============================================================
当前 APP 职能总览
============================================================
说明：
- 所有 APP 由 AppManager (autoload/app_manager.gd) 注册管理，
  定义资源位于 resources/apps/*.tres。
- 玩家入口为 scenes/pseudo_os/game_desktop.tscn，通过
  desktop_app_ids 控制实际暴露给玩家的 APP 列表。
- 列表按当前 game_desktop 默认顺序排列；之后是仅在编辑器/调试
  桌面出现的开发工具 APP。
- 显示名 = 玩家在游戏内桌面上看到的名字；app_id = 内部引用。

============================================================
一、玩家桌面默认 APP（game_desktop.desktop_app_ids）
============================================================

1. LinkChat（app_id: linkchat）
   - 世界观：玩家在游戏世界里使用的即时通讯/社交 App。
   - 职能：与女主等 NPC 的实时聊天界面；承载 NPC 主动发起话题、
     departure / followup、卡片消息（含 sbeam 商品卡、AVG 入口卡等）。
   - 关联：ChatManager、NpcInitiativeManager、SbeamManager。

2. Browser（app_id: browser，显示名 Browser）
   - 世界观：游戏内的虚拟浏览器，用来打开剧情网页、公告页和历史页。
   - 职能：保留预制 WebPageResource、缓存页、剧情 URL 和浏览历史；
     主页隐藏动态搜索/冲浪入口，未知 URL 直接显示“网页生成暂时关闭”。
   - 关联：BrowserManager、resources/browser_pages/*.tres。

3. 千度贴吧（app_id: community）
   - 世界观：以"千度贴吧"形态呈现的轻量论坛社区。
   - 职能：承接玩家主动消耗 AP 的社区探索；日常吧、教程吧、项目吧
     生成轻量帖子 DSL；首页提供自由搜索和随心一搜；帖子可转发给
     林夏并触发 followup 回复。数值消耗和状态变化来自行动配置。
   - 关联：CommunityActionManager、prompts/community_feed.md、
     prompts/community_seeds.json、prompts/community_followup_reply.md。

4. 休息（app_id: sleep，资源文件名为 home_app.tres）
   - 世界观：玩家在自家居所休息/推进时间的入口卡片。
   - 职能：触发睡眠/换日流程，结算每日状态。
   - 关联：HomeActivityManager、TimeManager、DateManager。

5. Map（app_id: map）
   - 世界观：游戏内城市/校园地图。
   - 职能：选择前往的地点，触发外出/移动相关活动。
   - 关联：TransitManager、ActivitySessionManager。

6. 开发工作（app_id: dev_work）
   - 世界观：玩家作为独立游戏开发者每日工作的核心面板。
   - 职能：只向玩家暴露"当前一个可执行任务"，玩家点击执行后立即
     完成（聊天讨论 / 小游戏 / 简单点击），同时静默派发后台工单
     生成实际 AVG 内容。所有"工单/Agent/AP"等细节对玩家不可见，
     文案统一使用"本时段"。
   - 关联：DevCycleManager、MinigameManager、WorkOrderManager。

7. 设定集 (KB)（app_id: knowledge_base）
   - 世界观：玩家与 AI 共同维护的项目设定集（世界观、角色、剧情、
     灵感笔记）。
   - 职能：以可视化卡片形式查看/编辑 knowledge_base/docs/*.json
     文档；同时是 Planner / Writer / Executor 等代理读写设定的
     统一来源。
   - 关联：KnowledgeBaseManager、prompts/work_order_planner.md。

8. 兼职直聘（app_id: part_time）
   - 世界观：兼职招聘平台。
   - 职能：浏览/接受兼职，进入对应兼职活动并结算收入。
   - 关联：PartTimeJobManager、ActivitySessionManager。

9. sbeam（app_id: sbeam）
   - 世界观：游戏内的同人/独立游戏发行与下载平台（"sbeam"）。
   - 职能：玩家在 sbeam 面板浏览并购买/下载 NPC 推荐的小游戏，
     触发 LinkChat departure/followup 与 AVG 窗口播放。
   - 关联：SbeamManager、scripts/date/date_scene_generator.gd、
     prompts/sbeam_scene_normal.md、sbeam_scene_dsl_preview.md。

10. 好买（app_id: shop）
    - 世界观：综合电商 App。
    - 职能：浏览商品、购买物品，影响背包/属性/状态。
    - 关联：ShopManager、ShopCatalogFactory。

11. dilidili（app_id: avg_player）
    - 世界观：蓝白配色的"dilidili"视频/剧情播放平台。
    - 职能：以 TopBar + 卡片网格形式展示历史与首页 Hero Banner，
      作为玩家观看已生成 AVG 剧情/章节/小游戏成片的入口；另有
      4:3 streaming AVG 直播窗口，用于自动时间轴字幕与 chat 留言流。
      历史只记录标题、时间和播放结果摘要；不再保存截图封面或提供
      历史重播。公有 API（play_event / play_scene_package /
      play_stream_package / enable_thumbnail_capture / playback_finished）
      保持兼容，其中 enable_thumbnail_capture 为空实现。
    - 关联：NarrativeProjectManager、StoryDirector。

12. 桌宠（app_id: desktop_pet）
    - 世界观：桌面陪伴小窗口。
    - 职能：在桌面常驻一个小尺寸窗口（280×430），承载陪伴/氛围
      互动。

13. 云节拍（app_id: music_player）
    - 世界观：音乐播放器 App。
    - 职能：作为 AudioManager 的 UI 控制层选择/播放 BGM；不再
      自建独立 AudioStreamPlayer，与 AVG Player 冲突时让位全局
      BGM。
    - 关联：AudioManager。

============================================================

玩家流程：

- Project Manager（project_manager）：项目管理。

- File Manager（file_manager）：文件管理。

============================================================
附：APP 注册与访问控制
============================================================
- 注册：AppManager._register_all_apps() 启动时加载
  resources/apps/*.tres 并调用 register_app()。
- 启动：AppManager.launch_app(app_id) → 实例化 entry_scene
  → WindowManager.create_window() 套窗口 → 记入 running_apps。
- 故事访问控制：_access_mode = none / whitelist / blacklist，
  剧情可临时限制玩家可启动的 APP（is_app_accessible）。
- 桌面过滤：Desktop.desktop_app_ids 为空 → 显示全量；非空 →
  按列表顺序过滤显示。
