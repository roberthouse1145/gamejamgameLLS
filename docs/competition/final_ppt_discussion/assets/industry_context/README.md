## 使用原则

- 保持 Logo 原始比例，不拉伸。
- 不把媒体图片标成“官方 Logo”。
- 行业背景页以两个产品为主，不堆叠过多品牌。
- 页面文字写“官方宣称”或“产品愿景”，避免把宣传能力直接当作质量结论。
