## 3. 产品形态

### 3.1 题材、美术、世界观

**题材**：Galgame × AI 共创

**世界观**：

2027年，一场由亚太互动创作者协会(APICA)主办的世界级 GameJam「ARCADE GRAND JAM」即将开幕。玩家是蓝鲸大学数字媒体艺术专业的大四学生，与女友兼搭档——林夏——组队参赛。

比赛采用严格的反预制措施：官方素材包赛日发放、必须使用官方 AVG 引擎 Lumina、主题开赛才公布。所有选手站在同一条起跑线上，比拼的不是资源堆砌，而是**创意的组织能力**和**搭档之间的默契**。

45天倒计时开始。你们要面对的不只是一个作品——还有彼此的关系、外界的目光、和即将到来的毕业。

**美术风格**：

- 二次元现代风，强调潮流感与几何构成
- 渐变配色（紫-蓝-粉-黄绿），高辨识度的角色设计
- 拟真 Windows OS 桌面 UI，沉浸式桌面操作体验
- 角色立绘 + 聊天界面 + AVG演出混合呈现

### 3.2 玩家会体验到什么

> **Day 1**
> 你打开了一个看起来就像 Windows 桌面的画面。右下角弹出通知——"林夏：比赛开始了！打开 LinkChat 我们先聊聊？"
> 你打开聊天软件，她已经在拼命发消息。你们讨论主角的性格，争论剧情走向，最终妥协在一个你们都不完全满意但又觉得"好像可以试试"的方案上。然后你打开工单系统，把讨论结果变成今天的第一个开发任务。
>
> **Day 15 — 第一个Demo**
> 你在 Lumina Engine 里第一次看到你们做的东西。片头出现了你刻意选的那首BGM，主角说出了你亲手填写的第一句台词。它并不完美——有的转场很生硬，有一段对话逻辑明显不对。但林夏的消息弹过来："虽然有点粗糙，不过……是我们做出来的东西诶。"
>
> **Day 45 — 结局**
> 作品提交了。你可以把这个 AVG 导出来，发给朋友。朋友玩的时候会看到你写的台词、你选的美术风格、你和林夏在 Day 23 那次争吵之后妥协出来的剧情走向。这不是你"玩了一个游戏"——这是你和一个人**一起做了一个游戏**。

### 3.3 核心玩法机制

游戏分为两层：玩家直接体验的**表层**是一个虚拟OS恋爱养成游戏；驱动这一切的**底层**是一套完整的AVG生成系统。

#### 3.3.1 表层：虚拟OS恋爱养成

玩家操作一个拟真的虚拟 Windows 桌面，通过桌面上的各种APP与林夏互动、推进开发、参与社区、打工赚钱。

**时间管理循环**

45天，每天 3 个时段（上午/下午/晚上），每时段 1 次行动。通过桌面APP执行行动——推进项目、维护关系、或应对现实。

**五大行动维度**

| 行动类型 | 效果 | 核心特点 |
|----------|------|---------|
| **开发工单** | +完成度/质量/稳定度，+压力 | 核心创作行动，林夏会给出主观评价 |
| **约会** | +好感, -压力，触发关系剧情 | 时间成本最高，但维系关系不可或缺 |
| **兼职** | +金钱 | 约会和购物需要钱，现实压力 |
| **社群参与** | +热度，触发舆论 | 双刃剑：正面关注 vs 负面评价 |
| **在家活动** | +好感/-压力，日常互动 | 闲聊、谈心、一起看东西、审视作品 |

**两层属性系统**

**林夏三维**（关系线）：
- 好感度 — 约会/闲聊提升，过度派工降低
- 压力值 — 开发工作增加，休息/约会降低，过高触发危机剧情
- 激情值 — 好的创意讨论提升，重复劳动/高压力降低，归零 = 燃尽

**项目四维**（成绩线）：
- 完成度 — 里程碑考核硬指标
- 质量 — 精细化工作提升
- 稳定性 — Bug修复/测试提升
- 热度 — 社群参与/宣传提升

**创意开发小游戏**

这不是"跟AI聊天就生成了一个游戏"。玩家需要通过一系列创意开发小游戏参与共创：

| 小游戏 | 体验 | 产出类型 |
|--------|------|---------|
| **创意决策** | 林夏抛出具体的创作选择题（"主角失忆后第一个找回的记忆是什么？"），你从 2~3 个 AI 生成的选项中挑一个，也可以自己写一个 | 🔴 产出型：决策沉淀为角色/世界观设定 |
| **对话补全** | AVG 场景展示上下文，你为角色把关键台词填进填空位。林夏会审稿：通过/建议修改/拒绝 | 🔴 产出型：台词嵌入 AVG |
| **情感标注** | 快速为台词判断情绪基调 | 🟡 校准型：微调演出质量 |
| **Bug 修复** | 翻牌配对，在预设 Bug 中找出错误 | 🟢 氛围型：增加完成度 |
| **代码排序** | 将打乱的伪代码行重新排列 | 🟢 氛围型：流程设计沉浸 |
| **代码打字** | 打字游戏，敲出 AVG 引擎伪代码 | 🟢 氛围型：编程手感 |

产出型小游戏的创意会真正改变最终作品。氛围型小游戏提供“我在做一个真正的游戏”的参与感。每局完成后林夏会根据表现给出感性反馈——这些反馈本身也是恋爱体验的一部分。

**里程碑检查**

| 节点 | 天数 | 你会看到什么 |
|------|------|-------------|
| 第一个Demo | Day 15 | 启动 Lumina Engine，你填写的台词从主角嘴里说出来了 |
| 半程展示 | Day 30 | 前半段完整故事可游玩，外界首次评价涌入 |
| 最终交付 | Day 45 | 完整作品提交，可导出、可分享 |

为了保证**超出预期的惊喜感**，我们刻意隐藏了测试和直接修改工程的入口。在结局之前，AVG工程对玩家是黑箱——你只能通过里程碑Demo看到阶段性成果。你知道自己填了什么创意，但不知道它们被组装成了什么样子。

未达标 → 林夏压力飙升 → 关系危机

#### 3.3.2 底层：怎么把创意变成游戏

**先澄清一件事**：表层恋爱线（林夏的故事）有人类预写的剧本节点兜底；但**底层你们要做的那部 AVG 作品，没有任何人类预写剧本**——它从零开始，由你和林夏共创。

那它靠什么不崩？靠一份你永远看不到的"**项目中央文档**"。

1. **固定基底**：题材锁死在"日式魔法异世界学院"，开局让你填一份创作基点（作品名、类型、基调、大纲）——这是整个作品的第一块砖
2. **持续沉淀**：此后你写过的每一句台词、每一次讨论的结论、每一个风格偏好，都会被后台的 AI 搭档整理进这份中央文档
3. **滚动生产**：AI 不会一次性把 45 天的 backlog 铺给你，而是**每轮只根据当前文档的最新状态，生成接下来 2~3 个开发任务**——你的讨论会真的改变之后要做什么
4. **静默落地**：你每点一次"执行"，后台就派出一组 AI（策划→编剧→脚本手），花几分钟把这个任务的内容写进项目里。**它们不会告诉你进度**

所以在结局前，你知道自己**填了什么**，但不知道它们被**组装成了什么样**。里程碑 Demo 是这个黑箱唯一的开口——到 Day 15 你会第一次看见自己写的台词从角色嘴里说出来。Day 45 提交时，整部作品可以一键导出，发给朋友玩。

> 技术实现细节（Agent 工作流、知识库 schema、AVG DSL 引擎）详见 AI 协作日志。

### 3.4 游戏寿命与传播

这是一款**一周目体验即核心**的单人联网游戏。45天的GameJam走到结局，玩家和林夏的故事就讲完了。我们不打算用人造的"重复可玩性"去拉长寿命——那会稀释一周目的重量。

**一周目之后，玩家带走的是一个真正的作品**：

- **AVG导出**：通关后可将你和林夏共同创作的AVG导出为独立可运行的包。这不是截图或回忆——这是一个你可以发给朋友玩的、完整的游戏
- **社交传播**：每个玩家导出的AVG都不一样（不同创意、不同台词、不同走向），天然具有对比和分享的话题性——"你的林夏做了什么故事？"

## 4. 市场前景

### 4.1 目标用户

| 用户群 | 画像 | 吸引点 |
|--------|------|--------|
| **恋爱/文字冒险玩家** | 18-30岁，偏好叙事驱动，接受日系/二次元美学 | "和有个性的女主谈恋爱"而非"攻略模板女角色" |
| **GameJam/独立游戏爱好者** | 有创作经历或憧憬，理解"限时做游戏"的浪漫与压力 | 体验GameJam的真实感受，无需真的会写代码 |
| **AI交互新奇体验者** | 对AI产品/Chatbot感兴趣，追求新型交互 | LLM在人类剧本框架内演绎角色，对话有温度而非模板 |
| **轻度创意表达者** | 想参与创作但缺乏技能 | "填对话"而非"学编程"，低门槛表达自我 |

### 4.2 我们发现了什么问题

市面上几乎所有AI游戏都在犯同一个错误：**给传统游戏加聊天框**。AI恋爱模拟、AI村庄经营、AI侦探——玩法不同，本质一样：让玩家打字，让AI回复。

这导致三个致命问题：
- **玩法割裂**：聊天框的出现破坏沉浸感，文本质量不可控。全自由聊天和打开ChatGPT加个立绘没有区别
- **输入输出失控**：玩家可能打破第四面墙、试图操控AI；AI可能三句话剧透凶手或死活不给线索
- **想象力悖论**：有想象力的玩家对AI期待越高失望越大，没想象力的玩家盯着输入框大脑空白

我们的解决方案：**用小游戏取代文本框**，约束输入而非自由文本；**把决策权留给代码**，AI只做演员不做导演；**让等待成为设计**，而非技术缺陷。

> 完整的设计推演过程见附件「策划思考：AI游戏的设计陷阱与我们的回答」

### 4.3 竞品差异

我们的真正竞品不是同品类游戏，而是三个方向上的替代选择：

**竞品A：传统Galgame**

> "我凭什么不买一部人类精心打磨的Galgame？"

|              | 传统Galgame | 我们 |
|--------------|------------|------|
| 玩家角色 | 消费者——看别人的故事 | 共创者——故事里有你的台词和选择 |
| 女主关系 | 脚本预设 | 人类编写节点剧本，AI在节点间即兴演绎 |
| 核心卖点 | 精致的叙事享受 | "这个故事里有我"的参与感 |

传统Galgame是阅读体验，我们是创作体验。参与感是我们的维度，不是质量。

**竞品B：AI创作工具**

> "我凭什么不用专门的AI工具做游戏？"

|              | AI创作工具 | 我们 |
|--------------|-----------|------|
| 定位 | 工具——最大化效率 | 游戏——最大化体验 |
| 搭档 | 没有，你和AI对话 | 有一个会开心、会疲惫的搭档 |
| 产出感受 | "AI帮我做了一个东西" | "我和她一起做了一个东西" |

AI工具追求"做出来"，我们追求"做的过程"。那些"不方便"让产出有了重量。

**竞品C：AI恋爱软件**

> "那边可以自由聊天、高度自定义，凭什么玩这个？"

|              | AI恋爱软件 | 我们 |
|--------------|-----------|------|
| 类比 | 超级马里奥制造（自由度高，玩家自己找乐子） | 超级马里奥兄弟（设计好的体验，保证下限） |
| 产出 | 对话记录（消费后消散） | 可导出的AVG作品（带得走） |
| 体验下限 | 取决于用户自己 | 人类剧本骨架兜底 |

这不是对话工具，这是一款有结局的游戏。

### 4.4 核心卖点

1. **“和女友一起做游戏”** — 极强的概念包装，天然具有社交传播力（“你的林夏做了什么故事？”）
2. **玩家的创意真的会变成游戏** — 不是选项A/B/C的假选择。你填的台词、定的人设、讨论的走向，会通过后台AI系统落地为可导出的 AVG 作品
3. **拟真桌面沉浸** — 虚拟 Windows OS 的完整体验：聊天、开发、刷论坛、看舆论，打破“游戏窗口”的边界
4. **约束设计保体验下限** — 人类编写剧本骨架兜底，不赌 AI 发挥。每个玩家都能获得有起承转合的完整故事

### 4.5 商业模式

**诚实回答：当前无法商业化。**

这款游戏是两项不成熟技术的融合探索：
- **AI驱动游戏内容生成**尚处于早期阶段，稳定性和可靠性未经大规模验证
- **LLM 游戏**作为品类本身不成熟——运行时 API 调用成本使得"每局游戏都烧真金白银"的商业模式无法成立

本作是一个**早产儿**，它证明了"用 LLM 驱动游戏内容生成"这条路可以走通，但距离商业化还需要等待 LLM 推理成本的持续下降。

> 如果我能解决成本困境，我早就从历史学专业转到人工智能专业了。

**如果技术成熟后的商业设想**：
- **买断制**：Steam 定价 ¥68 / $9.99
- **DLC扩展**：新女主角（不同性格/专业）、新赛事（不同主题/规则）、"另一面"DLC（林夏视角）

## 5. 开发规划

### 5.1 开发规划

**我们不会死磕一份详细的开发路线图。**

原因很简单：AI 的能力每几个月就会跃迁一次。我们今天为了让AI稳定工作而写的工程代码，可能在半年后被更强的模型原生替代。这不是偷懒，这是客观判断。

> 手机游戏的巨头不是在按键机时代死磕游戏的那些人，而是在触屏机成熟后开发游戏的人。

**当前阶段的定位**：

| 我们在做的 | 我们不做的 |
|-----------|-----------|
| 证明“AI驱动游戏内容生成”这条路可行 | 死磕面向商业发布的完成度 |

### 5.2 风险挑战应对

| 风险 | 等级 | 应对 |
|------|------|------|
| **AI成本与延迟** | 高 | 当前无解。关键对话预生成缓存 + 模板回退机制可以缓解，但不能根治——这是整个 AI 游戏品类的共同困境 |
| **内容质量不可控** | 中 | 人类编写剧本骨架，AI在骨架内演绎细节，玩家填充创意。三层约束确保下限 |
| **叙事深度 vs 自由度** | 高 | “固定骨架 + 可变细节”：关键剧情节点固定，中间过程由玩家创意驱动 |
| **属性平衡** | 中 | 45天×3行动 = 135个行动点，通过数值模拟验证多种策略路径均可通关 |
| **美术资产量** | 低 | 核心美术集中在林夏立绘（多服装/表情）+ 桌面UI；场景/CG通过AI生成 |
