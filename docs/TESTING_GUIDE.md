# AVG Engine 测试指南

## 启动项目

1. 在 Godot 编辑器中打开项目
2. 按 F5 或点击右上角的"运行"按钮
3. 项目启动后会显示一个模拟桌面，上面有4个应用图标

## 桌面基本操作

### 图标操作
- **双击图标**: 打开对应的应用程序
- 4个应用分别是:
  - **Scene Editor** (场景编辑器): 编辑AVG场景
  - **Project Manager** (项目管理器): 管理项目资源
  - **Game Previewer** (游戏预览器): 预览运行AVG游戏
  - **File Manager** (文件管理器): 管理项目文件

### 窗口操作
- **拖拽标题栏**: 移动窗口
- **拖拽窗口边缘/角落**: 调整窗口大小
- **最小化按钮 (-)**: 最小化窗口到任务栏
- **最大化按钮 (□)**: 最大化/还原窗口
- **关闭按钮 (×)**: 关闭窗口
- **点击任务栏按钮**: 聚焦/还原对应窗口

## 测试流程

### 测试1: 文件管理器 (File Manager)

**目的**: 创建新项目

1. 双击 "File Manager" 图标
2. 窗口应该显示两个列表:
   - 左侧: 用户项目列表 (可能为空)
   - 右侧: 模板列表 (应该有 "tutorial_project")
3. **测试创建项目**:
   - 在模板列表中选择 "tutorial_project"
   - 点击 "从模板创建" 按钮
   - 输入新项目名称 (如 "my_test_project")
   - 确认创建
4. **预期结果**: 新项目应该出现在用户项目列表中

**反馈要点**:
- [ ] 窗口是否正常打开?
- [ ] 模板列表是否显示 tutorial_project?
- [ ] 创建项目功能是否正常?
- [ ] 有无错误提示?

---

### 测试2: 项目管理器 (Project Manager)

**目的**: 管理项目资源

1. 双击 "Project Manager" 图标
2. 左侧应该有分类列表:
   - 场景 (Scenes)
   - 角色 (Characters)
   - 事件 (Events)
   - 变量 (Variables)
   - 资源库 (Resources)
   - 项目设置 (Settings)
3. **测试切换分类**:
   - 点击左侧不同的分类
   - 右侧内容应该切换
4. **测试场景列表**:
   - 选择"场景"分类
   - 应该显示项目中的场景列表
   - 双击场景应该打开场景编辑器

**反馈要点**:
- [ ] 分类列表是否显示?
- [ ] 切换分类是否正常?
- [ ] 各个面板是否有内容?
- [ ] 有无错误提示?

---

### 测试3: 场景编辑器 (Scene Editor)

**目的**: 编辑AVG场景

1. 双击 "Scene Editor" 图标
2. 界面应该分为三个区域:
   - **左侧**: 场景节点树
   - **中间**: 场景预览 + 命令编辑器
   - **右侧**: 节点属性 + 命令参数
3. **测试工具栏**:
   - 保存按钮
   - 添加节点按钮
   - 删除节点按钮
4. **测试添加节点**:
   - 点击"添加节点"按钮
   - 选择节点类型
   - 输入节点名称
   - 确认添加
5. **测试命令编辑**:
   - 在命令编辑器中添加命令
   - 选择命令类型 (如 DIALOGUE, NARRATION)
   - 编辑命令参数

**反馈要点**:
- [ ] 三栏布局是否正常显示?
- [ ] 节点树是否可以操作?
- [ ] 命令编辑器是否可用?
- [ ] 属性面板是否显示?
- [ ] 有无错误提示?

---

### 测试4: 游戏预览器 (Game Previewer)

**目的**: 预览AVG游戏运行效果

1. 双击 "Game Previewer" 图标
2. 界面应该包含:
   - 场景选择下拉框
   - 播放/停止按钮
   - 调试模式开关
   - 预览区域
3. **测试预览**:
   - 选择一个场景
   - 点击播放按钮
   - 观察AVG运行效果
4. **测试调试模式**:
   - 开启调试模式
   - 应该显示变量值等调试信息

**反馈要点**:
- [ ] 场景选择是否可用?
- [ ] 播放功能是否正常?
- [ ] 对话框是否显示?
- [ ] 有无错误提示?

## 快捷键

- **Ctrl+S**: 保存 (在 Scene Editor 和 Project Manager 中)
- **Delete**: 删除选中项
- **Space**: 播放/暂停 (在 Game Previewer 中)
- **Escape**: 停止预览

---

## 已知问题

1. **警告信息**: 启动时会有一些 "shadowed class name" 警告，这是正常的，不影响功能
2. **SubViewport 警告**: Scene Editor 的预览面板会有 SubViewport 大小警告，不影响使用
3. **空脚本警告**: file_manager.gd 可能显示空脚本警告 (Godot 缓存问题)
