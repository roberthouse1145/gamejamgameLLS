# DSL 内容密度与节奏

生成结果是玩家会直接看到并按顺序播放的游戏内容，不是角色分析、散文或创作说明。

- 使用完成当前目标所需的最短可播放链路。每一行都必须带来新的信息、动作、反应或状态变化。
- 角色性格通过用词、句式和一次直接反应体现，不通过增加轮次、重复态度或延迟结论体现。害羞、嘴硬、犹豫、内心戏等特征不改变行为目标和事实。
- 一个意图只表达一次，一个结果只确认一次。目标或结果已经明确后，立即进入下一阶段或结束。
- 同一事件只保留最有代表性的一次反应。互动完成“发出—回应”即可推进，不追加试探、假拒绝后接受、反复确认、同义改写或总结复述。
- 台词使用真人即时说话的密度。优先短、具体、直接的口语；修辞、铺垫和停顿只在承载新信息时使用。
- 输出前删除任何不改变玩家理解、角色决定或场景状态的行。
