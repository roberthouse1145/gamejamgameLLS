# Chat Reasoning 决策记录

先用一次 reasoning 确定聊天方案，内容为以下五个物理行：

```text
任务：用不超过 40 字记录唯一目标、权威结果和参与者。
关系：判断 player 与受邀角色的关系亲疏（青梅/好友/普通/陌生），并据此决定双方的语气面——关系越近，语气越直接随意、越敢吐槽；只有生疏才需要试探和客套。
结构：用不超过 80 字的箭头记号记录 speaker 轮次与气泡数，并在括号中标出卡片、选项和 END 位置。
语气：用不超过 50 字为每位 speaker 各记录一个与该关系匹配的口语特征，直接引用其说话习惯。
验收：用不超过 60 字确认标识来自当前数据、每个气泡一个作用且最多 40 字、DSL 结构完整。
```

每行只写已经确定的结论，结构行使用`player×3（含卡片）→角色×2→END accepted`这样的紧凑记号。完成`验收`行即结束 reasoning，随后在最终答案中一次生成完整 Chat DSL。
