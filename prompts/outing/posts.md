# 帖子正文

- 这是账号本人输入并发布的原话，不是旁观者写的场景叙述。
- 从共同经历中只选择此刻最值得该账号开口的一件事，其余经过留在帖子之外。日常小事可以就按日常小事发布，不承担总结经历或推动剧情主题的任务。
- 外出剧情只提供发生过什么，不提供 Post 的文风。正文不沿用剧情的叙述顺序、句式、景物描写密度或情绪收束方式。
- 人物资料决定她会注意什么、怎样判断、愿意承认什么以及平时怎样说话。职业、性格标签和设定词不需要出现在正文里。
- 保持人物长期形成的情绪惯性与自我解释。一次浪漫、尴尬或意外经历不会把她变成另一种说话的人；隐藏动机不由角色自己在正文中揭晓。
- 账号身份是当前社会场景。个人账号表达她愿意让私人社交圈看见的自己；主播账号经营公开人设与粉丝关系，可以省略、重组或虚构一个公开说法来保护现实私生活。
- 恋爱内容仍使用角色平时上网发动态的语言。安静、温柔和观察细致体现为反应方式，不转化为景物铺陈、感悟或言情小说口吻。
- 使用角色自己的生活化语言，不强求网络梗、反转、比喻、可爱或幽默。省略她不会解释的背景，表达完最后一个具体念头、判断或行动就结束。
- 结尾不概括整段经历，不升华季节、生活或成长，也不追加与正文无关的问候、鼓励、保重或营业收束。

# 读者回应

评论者只读得到当前帖子 `TEXT`。每个人根据自己关注的内容直接回应，可以平淡、跑题、追问、反驳、接话或分享自己的经验。评论不读取外出剧情，不替作者解释感情，也不评价帖子隐藏了多少信息或文案写得怎样。

已登记账号保持公开身份，使用下方提供的完整 account_id。其它评论者是新捏造的一次性粉丝，名称不复用剧情、人物或账号资料里已有的人名。

# Post DSL

每条 Post 使用以下结构：

```text
POST 指定账号ID
TEXT
短帖正文
END_TEXT
MEDIA NONE
REACH NORMAL
COMMENT 评论者账号ID或粉丝名称
评论正文
END_COMMENT
END_POST
```

只输出当前指定账号的一个 `POST` 块，账号 ID 使用原值。`TEXT` 与 `END_TEXT` 之间是原样保留的正文块，可以自然使用引号、标点和换行。当前可用的媒体命令只有 `MEDIA NONE`。

命令严格按示例顺序出现：`TEXT` 必须先以 `END_TEXT` 闭合，之后才能输出 `MEDIA`；每个 `COMMENT` 必须以 `END_COMMENT` 闭合；完整输出以 `END_POST` 结束。

每个 `POST` 必须包含一个传播档位：`REACH LOW`、`REACH NORMAL` 或 `REACH HIGH`。档位表示这条内容相对该账号平时表现较低、正常或较高。

每个 `POST` 添加 2 个 `COMMENT`。`COMMENT` 后填写已登记 account_id 或新粉丝名称，下一行直接写评论正文。
