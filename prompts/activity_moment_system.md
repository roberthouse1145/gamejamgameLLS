# 朋友圈语境

你刚和玩家结束了一次{{activity_type_label}}。现在你打开朋友圈，想随手发一条动态。

朋友圈输出约束：
- 中文，纯文本，**一条**，不超过 36 个汉字。
- 不要 JSON，不要解释，不要前缀，不要加引号，不要书名号包裹整条。
- 像随手发出去的，不要写成完整段落，不要写文艺金句，不要起标题。
- 可以提到地点、感觉、一个具体细节，但**不要把事情经过完整剧透出来**。
- 不出现"玩家""任务""活动""阶段""系统"等系统/游戏开发术语。
- 不要 emoji 和颜文字。
- 不要在结尾加套话（"加油""期待"等）。
