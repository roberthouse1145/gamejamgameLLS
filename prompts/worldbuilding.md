# 世界观设定

背景: 2027年，中国虚构城市澜京（原型南京），蓝鲸大学大四数媒专业
两人状态: 男女朋友 + AGJ 参赛搭档，校外合租公寓各有独立房间

---

## 帧语·新星叙事大赛 2027

基本信息:
  正式名称: 帧语·新星叙事大赛 2027（FSW 2027）
  俗称: "帧语大赛""新星大赛"
  主办: 帧语（视觉小说创作平台）
  本届主题:「异世界」（开赛日揭晓）
  比赛时长: 45 天
  形式: 全程线上开发提交，仅决赛需线下布展答辩

赛组:
  新星组（Rising Star）: 仅限全日制在校学生
  队伍规模: 2-5人，玩家和林夏两人队
  各组共享素材包和引擎，独立评审/奖金池

反预制条款（三大铁律）:
  1. 素材封印: 官方素材包由霞光工房制作，赛前绝密
  2. 引擎锁定: 必须使用帧语官方引擎 FrameLang Engine v3.2，赛日发放
  3. 主题封印: 开赛才公布主题，所有作品必须扣题

奖金:
  金赏: ¥100,000 + 帧语年度推荐位 + 线下展出
  银赏: ¥50,000 + 发行权谈判机会
  铜赏: ¥25,000 + 平台推荐
  最佳人气赏: ¥10,000（读者投票）

聚光灯机制: 参赛队可公开开发过程（直播/社媒），帧语平台提供流量支持。人气赏在公众展示期投票。宣传可选但影响人气赏和发行谈判。

---

## 虚拟桌面应用

游戏交互界面是拟真虚拟 Windows OS。核心应用:

  LinkChat: 即时通讯，与林夏及其他NPC的主要交流渠道
  Lumina Engine: 官方AVG开发引擎，比赛核心工具
  SBeam: 类Steam游戏平台，比赛作品最终上架处
  浏览器: 虚拟互联网，比赛论坛/社媒舆论/攻略
  文件管理器: 项目文件和素材管理

  AGJ 官方论坛: 选手和观众讨论，开发日志区

## 时间与节奏

  比赛周期: 45天，每天一个游戏回合
  行动有机会成本: 开发/休息/兼职/约会/杂事之间分配
  阶段性 Demo 节点: 比赛期间若干提交节点，只有此时能看到作品运行效果
  Demo 质量影响舆论反馈和林夏情绪状态
