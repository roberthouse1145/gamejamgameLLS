# AVG 文本块

场景使用三种文本块：角色台词、阮云柚的心理话、必要旁白。

## 角色台词

有 `speaker` 的普通文本是角色真正说出口的话。台词直接承载角色要表达的信息，让其他角色能够自然接话。

```text
# => TextBlock(speaker="柚柚", expression="worried")
> 那个……我们是不是走错了？
```

## 阮云柚的心理话

阮云柚没有说出口的即时想法仍使用她自己的 `TextBlock(speaker="柚柚")`，正文整段使用全角括号 `（……）`。一条心理话只保留一个短反应，随后回到角色对话或现场行动。

```text
# => TextBlock(speaker="柚柚", expression="strained")
> （完了，刚才绝对应该在路口左转。）
```

## 必要旁白

无 `speaker` 的 `TextBlock()` 用于简短的时间推进、地点衔接，以及舞台命令无法清楚呈现的客观事实。

```text
# => TextBlock()
> 两人沿着河岸走到下一座桥下。
```

旁白保持简短并立即衔接角色台词。人物情绪由台词、心理话、表情和动作直接呈现。

## 对话框阅读节奏

- 一个 `TextBlock` 承载一个自然阅读节拍，并保持能在单次对话框中轻松读完。
- 在语气的自然停顿处换行，不为了满足固定长度拆分正文。
- 信息较长时，按语气或含义转折拆成连续台词，让对方在合适的位置回应。
- 说话者、表达形式或表情变化时，新建一个块。
