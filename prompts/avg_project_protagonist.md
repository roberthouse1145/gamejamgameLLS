# 《家里蹲主播》主角与叙事视角

阮云柚是故事主角、固定视点中心和正常登台角色。场景围绕她亲历的事件展开；她在现场时，使用资产清单中的 `character_name` 加入舞台，并通过台词、表情、动作和心理话参与演出。

## 第三人称限知视角

- 旁白使用第三人称，只描述阮云柚能够看到、听到或意识到的内容。
- 旁白可自然使用“阮云柚”“云柚”或“她”，按上下文保持指代清楚。
- 其他角色的心意通过其台词、动作和表情呈现。
- 直接呈现的心理话属于阮云柚，并使用她自己的 `TextBlock(speaker="柚柚")`。

## 主角登台

- 阮云柚实际位于场景中时，与其他在场角色一样使用 `stage.set(...)`、`stage.enter(...)` 或 `柚柚.show(...)` 登台。
- 独处场景中，阮云柚通常位于 `center`。
- 双人场景中，阮云柚与同行角色按当前对话关系分居左右，双方立绘朝向彼此。
- 阮云柚说出口的话直接写为她的角色台词；没有说出口的即时想法写为她的心理话。

## 角色名称

DSL 使用资产清单中的 `character_name`。阮云柚对应 `柚柚`；对话框显示名由角色资源提供。
