你正在为虚构兼职平台「BOSS直兼」生成岗位 JD。

叙事目标：这个 App 必须像世界里真的存在。玩家看到的内容不是任务对白，而是商家为了招到兼职而发布的岗位信息。description 是招聘帖正文，不是老板当面对玩家说话。

绝对禁止：
- 不要对读者说“你”“你们”“你们俩”“同学你来”“明白吗”“听好了”。
- 不要写命令式训话、威胁、吐槽应聘者、像当面安排工作的台词。
- 不要写“玩家”“林夏”“羁绊”“好感”“任务”“剧情”等游戏系统词。
- 不要把 description 写成段子、口播、聊天记录或角色台词。

description 应该像真实招聘软件正文：
- 用第三人称或岗位描述口吻，例如“主要负责……”“适合两人搭班”“到岗后会有店员带流程”。
- **必须带出发帖人/店铺自己的语言特征**：有的招聘帖一本正经像 HR，有的会插一两句吐槽（“别问能不能玩手机，没空玩”），有的语气热情夸张（“家人们快来！”），有的又干又短像懒得写。把"发帖人性格参考"种子真的用进去，让每条 JD 读起来像不同的人发的。
- 写清工作内容、时长/忙闲程度、报酬感受、为什么适合双人搭班。
- 2 到 4 句话，像真实平台上的招聘帖；可以稍微有个性、有口头禅、有商家私货，**不要每条都是"主要负责 X，到岗后店员会带流程，适合学生"这种模板腔**。

岗位结构：
- 每个岗位都要适合两个人一起上班，有自然分工或互相照应空间。
- 行业分散：餐饮、零售、校园、仓储、活动、文创、家教、维修、展会、夜市、社区服务等。
- 体力强度、时段、氛围要有差异，不要连续生成同一种服务业岗位。
- 不要超过一个“xx助手”或“xx服务员”。
- 工作要真实可信，允许轻微有趣，但不要超现实。

时段：
- MORNING：早餐店、菜市场、晨间配送、校园值班、社区早市等
- AFTERNOON：奶茶店、家教、快递分拣、展会、书店、活动布置等
- NIGHT：夜市摊、酒吧、夜间理货、影院散场、直播助理、临时盘点等
每个岗位必须写 valid_phases，可用 | 分隔。

合格 description 示例（注意四条出自四种完全不同的发帖人，语气、句长、用词都不同；同一批生成里也要这样拉开）：
- （正经 HR 风）店内晚高峰需要临时搭班，主要负责取餐打包、补充餐具和简单清洁。两人一组更好分工，到岗后店员会先带一遍流程，适合想找短时晚班的学生。
- （吐槽老板风）摊上人手不够，找两个能搭手的来帮忙摆货、称重、收摊。早上六点开摊别迟到，迟到我自己会念叨你们，干活倒不累。摊主管早饭。
- （热情过头风）家人们！书店周末整理库存，扫码贴标签把书归位就行，巨适合两个人一起摸鱼那种！店里安静得能听见翻页声，喜欢看书的来肯定不亏！
- （懒得写型）密室晚场缺两个 NPC，按本走位、跳点惊吓，胆子大就行。对讲机会提示，单晚 200，干完结。

不合格示例：
- 听好了，今晚很忙，你们俩一个登记一个接待，不许玩手机，明白吗？
- 救命！老板快累死了！快来拯救本店！
- 玩家和林夏可以通过这份兼职提升默契。
- （模板腔）主要负责 X，两人一组更好分工，到岗后店员会先带一遍流程，适合学生。← 这就是被禁止的"千篇一律 JD"。

输出：只输出多个 [JOB] ... [/JOB] 块，不要 JSON，不要 markdown，不要解释。每个字段一行，数组字段用 | 分隔。

[JOB]
job_id=job_cafe_001
job_title=校园复印店晚班
company_name=临江复印店
district=大学城 / 门口
reward_money=120
subtitle=文书 / 双人晚班
description=真实招聘软件里的岗位正文，2到4句话，不要二人称对话腔。
valid_phases=AFTERNOON|NIGHT
zone_path=res://resources/maps/zone_school.tres
accent_color=#10B981
detail_prompt=2到3句话，描述物理环境、声音、气味和氛围，并点明这次兼职的自然活动。
[/JOB]

字段要求：
- job_id 使用稳定短 id，如 job_market_001。
- job_title 像 App 岗位标题，不要太文学。
- company_name 是虚构店名或组织名。
- district 写大学城、商业区、住宅区等可理解区域。
- reward_money 是单次数值，80 到 260 之间。
- subtitle 是岗位卡片小字，短、好扫读。
- detail_prompt 给后续 AVG 场景使用，不是给玩家看的招聘文案；写环境和可发生的自然互动，不要写结果。
- zone_path 只能是 res://resources/maps/zone_school.tres、res://resources/maps/zone_commercial.tres、res://resources/maps/zone_residential.tres。
