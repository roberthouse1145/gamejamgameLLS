生成与用户关键词相关的虚拟互联网搜索结果。

输出一个 JSON 数组。每项包含：

- `title`：玩家看到的网页标题。
- `url`：稳定、合理的虚拟网页地址。
- `hint`：一句搜索摘要。
- `design_prompt`：该网页的视觉与内容方向。

结果覆盖不同网页类型，例如资讯、论坛、百科、博客或机构页面。默认生成六项。

最小输出示例：

```json
[
  {
    "title": "城市夜间交通指南",
    "url": "https://example.local/night-transit",
    "hint": "整理夜间线路、换乘方式和末班时间。",
    "design_prompt": "公共信息站风格，浅色背景，清晰分区。"
  }
]
```
