- 版本：v0.8

- 状态：核心框架、角色、卡牌、素材、技能成长体系已收敛
- 参赛目标：腾讯 2026 游戏创作大赛 AI 赛道
- 本次变更：**技能成长改为"事件 + 实战"**（删除"练习"动作——打工/打游戏/约会/直播都是事件本身）；新增五级累计 EXP 阈值（100/300/600/1000）与事件 × 系别 EXP 映射表、直播实战 EXP 规则（行为卡 +5/张，含锁定卡）；**主播等级与技能等级分离**（主播等级 = 经营成果里程碑，管预算/修饰槽/解锁；技能等级 = 事件+实战 EXP，管系数/门槛）

## 1. 游戏概述

### 1.1 一句话简介

玩家操作一个**桌面 OS 界面**，扮演被白富美青梅欺骗、签下 MCN 合约的**家里蹲宅女**，靠直播打工还债——否则将背上巨额违约金，从此沦为青梅的宠物。

### 1.2 核心体验

- 玩家操纵的是**女主角**，但她的性格底色很重，玩家的选择会被她的性格过滤——降低玩家的表演压力
- 女主是**家里蹲**：看番、打游戏、买谷子，这些宅生活本身就是直播素材（消费即生产）
- 喜剧外壳、压力内核（基调待最终确认）

### 1.3 设计支柱（五条分界线）

1. **非 Chat Game**：克制自由输入。大部分情况下玩家不做自由输入，而是通过**间接输入（日程安排、组卡、菜单选择）+ 游戏数值**驱动 LLM 演绎
2. **决策前置、演出放映**：直播中零决策、零打字；决策全部发生在**准备阶段**与**结算后**
3. **数值是真相，LLM 是表达**：核心结果由代码预结算，LLM 只负责把结果演出来
4. **消费即生产**：宅生活 → 素材 → 直播内容 → 收益 → 更好的宅生活
5. **粉丝是向量，朋友是角色**：粉丝只是数值与氛围，朋友才是故事（唯一具名例外：榜一 = 鹿铃，见 8.5）

## 2. 核心循环

```
宅生活（看番/打游戏/买谷子）
      ↓ 产出
     素材（内容含量）
      ↓
组卡开播（素材定题面：槽位+锁定卡；行为卡拼接 + 修饰卡加滤镜）
      ↓ 预结算 + LLM 演出
   直播放映（3~5 分钟游戏时间）
      ↓
   结算（在线/涨粉/打赏/事故/粉丝构成）
      ↓
下播处理（舆情菜单、朋友消息、下播日记）
      ↓
 金钱 → 还债/升级设备/买更多素材
 压力/宅欲/孤独 → 软约束下一天的安排
```

## 3. 时间结构与流程

### 3.1 90 天 / 6 期判定

- 总时长 **90 天**，每 **15 天**一次契约判定，共 **6 期**
- **判定失败** → 提前进入一般结局判定（最后 2~3 天为"结局周"）
- **撑到 90 天** → 进入好结局判定
- 好结局、一般结局均为**多结局**

### 3.2 每日 3 时段

- 每日 **上午 / 下午 / 晚上** 3 个时段，每时段一次行动
- 行动类型：打工 / 宅生活 / 陪朋友 / 直播 / 休息——全部是**事件**（事件即行动；技能 EXP 从事件与直播实战中获得，见 5.8；**不存在"练习"动作**）
- 直播频次由玩家自选，不做硬性排班——约束来自数值而非规则（见 3.3）

### 3.3 软约束原则

- **直播频次由玩家自选**，不做硬性排班
- 约束来自数值而非规则：**三属性（压力/宅欲/孤独）+ 素材库存（一次性，见 6.1）**
- **压力过满 → 坏结局线；宅欲过满 → 摆烂；孤独过满 → 社交事故**

## 4. 数值系统

### 4.1 分类总则：属性 / 资源 / 成长 / 关系

| 类别 | 内容 | 说明 |
|---|---|---|
| **属性**（女主状态，0~100，波动、阈值、喂 LLM） | 压力、宅欲、孤独 | 见 4.2 |
| **资源**（非属性） | 金钱（货币）、时间（3 时段）、素材库存（一次性素材，见 6.1）、演出预算（单场卡牌强度上限，每场满额，见 5.9）、热度/收益/粉丝构成/炎上（跨场） | 金钱就是金钱，不是属性 |
| **成长**（非属性） | 五维技能、**当前人设**的熟练度/固化度（转生后冻结归档，见 4.10）、主播等级（演出预算 + 修饰槽 + 解锁）、知识面 | 长期积累 |
| **关系**（非属性） | 各朋友的好感、信任、依赖 | 各自独立 |

### 4.2 三属性（常驻可见条 ×3，黄油式驱力）

| 属性 | 涨的来源 | 消解方式 | 高了会怎样 |
|---|---|---|---|
| **压力** | 直播、打工、炎上、债务、判定临近 | 宅生活、陪朋友、休息 | >60% 演出降质 / >80% 摆烂 / **100% = 坏结局** |
| **宅欲** | 被迫做"正事/表演"（打工、直播、陪人） | 宅生活（看番/游戏/买谷） | >70% 心不在焉、演出打折 / >90% 摆烂（"下周再努力吧"） |
| **孤独** | 宅生活（隔绝）、**直播（单向关注不填坑）** | 陪朋友 | >70% 下播日记变丧 / >90% 社交事故（直播中绷不住人设） |

**关键洞察（情感内核）**：直播**同时涨宅欲和孤独**——她被迫当众表演，但观众是单向关注，没有人真的认识她。合约逼她做的是唯一"喂不饱她、反而饿死她"的工作。

### 4.3 阈值与释放事件（黄油式手感）

- **满值释放事件**：
  - 宅欲满 → 深夜爆肝游戏事件（时间损失 + 素材爆率）
  - 孤独满 → 半夜给青梅发消息（关系事件，露出破绽）
- **交叉作用**：
  - 压力高时，宅生活回宅欲更快（报复性消费）
  - 宅欲高时，直播扣压力更多（被迫营业更痛）

### 4.4 防刷法检验（属性的存在意义）

| 刷法 | 后果 |
|---|---|
| 只直播 | 三属性全涨 → 演出崩、事故、摆烂 |
| 只打工 | 宅欲↑↑ → 摆烂；且合约进度停滞 → 判定失败 |
| 只宅生活 | 孤独↑↑ → 社交事故；且没钱 → 判定失败 |
| 只陪朋友 | 判定失败（自然结果） |

素材库存与合约判定是天然刹车——不需要精力类假刹车。

### 4.5 被否决的数值及理由

| 数值 | 否决理由 |
|---|---|
| 精力 | 3 时段已封顶每日行动次数，精力是第二根行动条，冗余 |
| 快乐值 | 宅生活本身已被机制奖励（素材 + 灵感 buff），再立一条即重复 |
| 激情值/动力 | 用"压力高时休息效果打折、下播日记语气变丧"表达，不做第二条压力条 |
| 健康条 | 用压力慢性效果表达，上限管理代替第二根条 |

（孤独曾被否决，后因承担"防刷法 + 朋友系统驱动"的双重职责而被采纳为属性。）

> **"精力"被否决 ≠ "演出预算"被否决**：被否决的精力是**每日行动条**（与 3 时段重复，见上表）；演出预算是**单场牌组强度上限**（构筑约束，见 5.9），作用域完全不同——前者管"一天能做几件事"，后者管"一场能编多重的节目"。

### 4.6 五维技能（成长数值核心）

**五个互不包含的维度，对应五个身体部位/能力层：手 / 嘴 / 声 / 演 / 技。**

| 维度 | 一眼即懂 | 边界（不含什么） | 底层 |
|---|---|---|---|
| 🎮 **游戏力** | 玩游戏的水平（操作、通关、理解） | 不含说话、不含搞笑 | 手 |
| 🗣️ **杂谈力** | 会聊天、会接梗、能救场；**含接弹幕、回 SC、怼黑粉** | 不含游戏操作、不含扮演 | 嘴 |
| 🎤 **歌唱力** | 唱歌、音准、声线质感（歌回 / ASMR / 电台） | 不含演技 | 声 |
| 🎭 **演出力** | 演人设、夹嗓子、卖萌、营业——"皮套后面的表演" | 不含真本事、不含技术 | 演 |
| 💻 **杂项力** | 设备、OBS、调音、剪辑切片等台后技术 | 不含任何台前能力 | 技 |

**设计决定：**

- 曾设第六维"反应力"（接弹幕/应对黑粉），因与杂谈力同为"靠嘴输出"、在数值上作用于同一位置而**并入杂谈力**——两个技能解释同一场直播就是冗余
- **技能不加成"直播类型"，而是加成对应系别的卡牌**（见 5.5）——避免"一维服务一类直播"的查表化，保住组卡策略性
- 技能第二作用：**高级卡的解锁门槛**（如演出力 Lv.3 解锁《瞬间变声卖萌》）
- 成长来源：**事件 + 实战**——事件（打工/宅生活/陪朋友/剧情）按类型给对应系 EXP；直播实战按本场行为卡系别给 EXP（详见 5.8）。**不存在"练习"动作**
- **知识面**（深度/广度，素材利用率放大器）保留为独立成长值，不占五维（是否并入杂项力：待定）

### 4.7 其他长期数值

- **人设数值**（每个档位一套）：熟练度、固化度
  - 长期扮演同一档位 → 熟练度↑（演出基础倍率↑），但同时固化度↑（新粉转化率↓）
  - 人设档位 ≠ 人设数值：档位是"选择演什么"，数值是"演得多熟/观众多固化"
- **关系**：与每个朋友的好感、信任、依赖（各自独立）

### 4.8 跨场数值（不上常驻条）

- **粉丝构成向量**（见 4.9）
- **炎上值**：跨场累计，压力源放大器
- **契约进度**：债务余额、6 期判定完成情况

### 4.9 粉丝构成向量（五类互斥）

**结构**：`路人 R / 男粉 M / 女粉 W / 核心粉 C / 黑粉 B`，归一化百分比：R+M+W+C+B = 100%。路人无性别；核心粉、黑粉从男女粉转化而来。

**每场直播后的变动流程：**

1. **基础扰动 Δ** = Σ(行为卡 fanBias) + 素材 affinity 修正 + 事故修正（事故 → B↑、R↓）
2. **新增路人** = 峰值在线 × 转化率；转化率 = base × (1 − 0.8 × (C+B))
   - **核心粉与黑粉占比越高，新粉越难流入 —— "观众固化"的数值落地**
3. **路人 → 男女粉**：按质量轴留存系数（见 7.3）
4. **男女粉 → 核心粉**：打赏/舰长事件概率转化（核心粉 = 金主）
5. **黑粉**：增 = 炎上量 × 黑化系数；每场自然衰减 10%（淡出，但节奏事件可复活）
6. **归一化**

**反哺（让向量真正影响决策）：**

- **变现**：打赏权重 = (0.3R + 0.6(M+W) + 1.6C − 0.5B)——核心粉是金主，"转化核心粉"是经营目标
- **破圈**：新粉转化率 ∝ R 占比。长期演同一人设 → 结构偏科 → 破圈停滞
- **舆论**：B > 15% → 炎上概率翻倍、事故放大，并进入状态快照（LLM 演"黑粉蠢动的弹幕氛围"）
- **人设切换 = 毕业转生**（唯一途径，见 4.10）：中之人同时只能扮演一个 Vtuber，开播前不可换皮套。切换是资产级事件，不再是轻量惩罚
  - 这收紧了核心张力：**专精 → 熟练度↑、变现↑，但固化 → 增长停滞；破局只能转生 → 资产清零、从新皮套重来**
- **演出语境**：构成向量作为状态快照的一部分给 LLM，LLM 只演"氛围"，不演有名有姓的粉丝个体——**唯一例外：榜一鹿铃**（见 8.5，具名角色，单独人物卡）

**显示简化**：一根五段条形图 + 总粉丝数 + 一句提示（如"黑粉扎堆"/"观众结构固化"），玩家看趋势，不读数字。

### 4.10 毕业转生（人设切换的唯一途径）

**为什么存在**：现实中一个中之人同时只能扮演一个 Vtuber。开播前随便选皮套是玩法妥协，破坏代入感——人设卡不能直接切换。换皮套 = 旧 Vtuber 毕业、中之人带经验转生为新皮套，是**资产级事件**，不是轻量惩罚。

**规则：**

- **触发**：玩家主动发起（入口待定：直播姬应用内 / 管理中心），无冷却，但门槛阻止滥用（见下）
- **门槛（待测试）**：当前人设累计直播场次 / 粉丝规模 / 主播等级达到条件才可发起转生
- **效果**：
  - 当前人设的熟练度、固化度**冻结归档**（不再变化，不可再扮演）
  - 旧人设卡从图鉴"扮演中"变为"已毕业"
  - 切换为新人设档位（**新人设 = 转生的解锁目标**，转生即新档位的获取方式，解决"新档位从哪来"）
  - 与皮套无关的资源全部保留：技能、知识面、素材库存、金钱、关系、契约进度
- **粉丝构成向量重建（转生红利，防"纯清空=永不转生"）**——转生前 `R/M/W/C/B`，转生后初始盘按残留规则生成（比例待测试）：
  - **路人 R ×0.5 继承**：新皮套自带路人盘（圈内消息传播）
  - **一般粉 M/W ×0.2 跟随**：一部分老粉陪皮套走
  - **核心粉 C：×0.1 认出来（→新皮套 C）；×0.3 回踩（→B）；×0.6 流失**：金主被毕业伤得最深——"你越成功，转生越痛"
  - **黑粉 B ×0.5 跟随**：黑粉记仇，跟着新皮套继续黑——**转生换不掉你的黑粉，只会丢掉你的金主**
  - 归一化后粉丝总数大幅缩水；熟练度、固化度重置为新人设初始值（增长压制解除）
- **与固化度联动**：固化度压制新粉转化 → 长期演同一人设增长停滞；转生解除压制但资产清零。决策 = "存量变现 vs 清零重来"
- **数值叙事**：与 Build 6（地雷系，4.9 / 5.14）形成全游戏最狠闭环——地雷系核心粉转化全游戏最高、黑粉共生，**转生时金主丢得最干净、黑粉跟着走**：你越成功，越走不出去

## 5. 卡牌系统

### 5.1 总览（90 张 = 行为卡 70 + 修饰卡 20）

- **两个物种**：
  - **行为卡（70）**：节目单上的"节目"，带**左右槽位接口**（拼接用，见 5.3），按**五技能系别**划分：🎮 游戏 14 / 🗣️ 杂谈 16 / 🎤 歌唱 12 / 🎭 演出 14 / 💻 杂项 14（各系含开场卡 / 中坚卡 / 收尾卡 / 高阶卡）
    - v0.3 的"方向树"（游戏/ASMR/杂谈/唱见/整活）并入五系：ASMR、唱见 → 歌唱系；整活 → 演出系或杂项系
  - **修饰卡（20）**：全场的"滤镜"，无槽位接口、不占节目槽，分**语气卡 12（腔调/声线/话术）+ 企划卡 8（本场规则）**（见 5.11）
- 解锁分层：基础卡（前 15 天）/ 进阶卡（30 天后）/ 王牌卡（60 天后）
- **槽位由素材决定**：素材提供 `slots`（节目槽数量）与 `lockedCards`（锁定卡 + 位置，见 6.6）——素材的"厚度"就是节目单的长度，素材越硬槽越多（大作RPG 5 槽 / 谷子开箱 2 槽）。**主播等级不再提供节目槽**，收缩为：演出预算上限 + 修饰槽（Lv3/8）+ 卡牌解锁（见 5.8）
- **空槽规则**（槽位有空）：允许空着，每个空槽全场基础盘 ×0.9（"节目太水"），链的接缝判定跳过空槽（透传）——软惩罚，不卡死前期卡池
- **分区取消**：玩家不选"直播分区"——素材已隐含内容类型（游戏素材=游戏回，游戏回忆=杂谈回），本场"是什么直播"由素材 + 卡组主导系别自然涌现，LLM 按主导系别演绎。选分区是多此一举
- 分布表 / 技能树 / Build 原型见 5.12 / 5.13 / 5.14

### 5.2 卡面双标识（两套标识，不混淆）

每张卡有两套彼此独立的标识，用不同视觉语言：

| 标识 | 视觉 | 作用 |
|---|---|---|
| **技能系别** | 图标（🎮🗣️🎤🎭💻） | 决定这张卡吃哪个技能的加成（见 5.5） |
| **槽位接口** | 卡牌**左右两端的 4 个槽位**（左端凹孔 / 右端凸柱，亮 = 激活；族记号 1~4 / A~D / W / U，见 5.3） | 决定卡与卡的连接关系（填充率，见 5.3） |

卡面信息分层：正面只放 系别图标 + 双端接口族 + 四轴注入；详情（连击、fanBias、压力消耗、解锁条件）悬停展开——控制决策负担。

```text
┌─────────────────────┐
│ ⬅B  激情吐槽  B➡   │  ← 左接口族 B = {2,4} / 右接口族 B
│ 🗣️ 杂谈系 · Tier 1  │
│ 噱头+2 效果+3 质量-1 │
│ 风险+1              │
└─────────────────────┘
```

### 5.3 槽位接口系统（拼图连接）

**纯位置接口，零语义**：每张卡左右各 **4 个槽位（1~4）**，无颜色、无形状。卡声明两个接口：

- **左接口 L** ⊆ {1,2,3,4}（凹孔，接收）
- **右接口 R** ⊆ {1,2,3,4}（凸柱，输出）

**接口族记号**（卡面显示用，一眼看出形状）：

| 族 | 激活槽位 | 宽度 | 定位 |
|---|---|---|---|
| 1 / 2 / 3 / 4 | 单槽 | 窄 | 稳定弱卡（好被填满） |
| A = {1,3} | 双槽 | 标准 | 标准族 |
| B = {2,4} | 双槽 | 标准 | 标准族 |
| C = {1,4} | 双槽 | 标准 | 两端族 |
| D = {2,3} | 双槽 | 标准 | 中段族 |
| W1~W4 | 三槽 | 宽 | 强卡（难被填满） |
| U = {1,2,3,4} | 四槽 | 万能 | 陷阱卡 / 终极强卡 |
| ∅ | 空 | — | 开场卡左端 / 收尾卡右端 |

**填充率（核心规则）**：前一张卡的右接口（凸柱）**填充**后一张卡的左接口（凹孔）。

**填充率 r = |R前 ∩ L后| ÷ |L后|**

功效只对**后卡**结算（它被接得牢不牢），按 r 四档：

| r | 后卡功效 |
|---|---|
| **1（满填充）** | ×1.2（最大功效） |
| 0.5 ≤ r < 1 | ×1.0 |
| 0 < r < 0.5 | ×0.9 |
| 0（空接） | ×0.8，风险 +10% |

**基础注入按"左接口宽度"付费——越难被填满的卡越强：**

| 左接口 | 被填满难度 | 基础注入 |
|---|---|---|
| 1 槽 | 任何前卡都能填满 | ×0.85（弱、稳） |
| 2 槽 | 标准 | ×1.0 |
| 3 槽 | 需要前卡 3 根柱全插 | ×1.2（强、高方差） |
| 4 槽 | 几乎不可能填满 | ×1.35（陷阱/终极赌狗） |

**右接口 = 纯能力维度，不收费**：右接口宽（3~4 槽）= **桥梁卡**，能把难伺候的后卡填满——稀有资源。**万能适配器**（右 U，仅 2 张：瞬间变声卖萌 / 多机位企划）是稀缺桥梁。

**结构规则：**

- 开场卡：左接口 = ∅（不需要被填，功效按基准，不受入端影响），右接口负责填满第二张卡
- 收尾卡：右接口 = ∅（不填别人），功效看自己被填率。**非必需**（初始 2 槽放不下）；价值是收尾奖励（观众留存↑ / 压力回复）——中期槽位多了以后自然进入构筑
- 空接（r=0）也可以塞：惩罚是效果打折 + 风险，不是禁止——赌狗保留操作空间
- **空槽**：素材给的槽位允许留空，每个空槽全场基础盘 ×0.9；链的接缝判定**跳过空槽**（卡 i 右接口直接接下一个有效卡的左接口；链首空槽等同开场、链尾空槽等同收尾）
- **锁定卡**：素材锁定卡占据指定槽位、不可拖出（松锁变体可换位置，见 6.6）；锁定卡**不消耗演出预算**（它是题面不是选择，见 5.9）
- **全链满血奖励（"行云流水"）**：链上每张卡 r=1 → 全链 ×1.1——"尽可能所有链路联通"的完整表达：不是接得上，是每一段都填满

**示例 build（满血链 vs 赌狗链）：**

```text
A 标准满血链：∅|A 正经开场 ▸ A|A 硬核攻略 ▸ A|∅ 通关感言
              两处接缝 r=1，全链满血 ×1.1
B 宽卡赌狗链：∅|W1 元气开场 ▸ W1|B 高能操作秀 ▸ B|∅ 明天再战
              高能操作秀左 W1（×1.2）需前卡右含 {1,2,3}；元气开场右 W1 恰好填满
              → r=1 → 1.2 × 1.2 = 1.44 超模；若换窄前卡则只发挥 1/3
C 断链代价：  ∅|A 正经开场 ▸ B|B 激情吐槽 → A∩B = ∅ → r=0 → ×0.8 + 风险 10%
              想吃跨族强卡 → 需要持有桥梁卡（右 W 族 / U）或吃断链惩罚
```

**为什么没有情绪**：v0.4 的 4 色情绪（热烈/冷静/温和/丧气）被废弃——一是"四种情绪 cover 不了直播场景"；二是颜色语义与槽位位置叠加复杂度爆炸。**凹凸槽就是凹凸槽**：纯机械接口，不承载语义。槽位 1~4 不代表任何东西，就像拼图接口只有匹配功能。

**LLM 演出指导来自卡牌内容本身**（各卡 prompt），不再有"情绪曲线脚本"——卡序（节目单）进入状态快照，LLM 按顺序逐拍演绎即可（见 11.2）。

**UI 原则——不评头论足**：卡面只显示接口族与数值，引擎**不弹**"⚠️ 不匹配警告"或"💡 建议换卡"。匹配判断是玩家自己的功课，策略游戏不对玩家的构筑指手画脚。

### 5.4 四轴注入（卡牌的作用目标）

一场直播的中间结算层是**四轴**，每张卡对四轴的注入方向不同——这是卡与卡的真正区别：

| 轴 | 含义 | 换算去向 |
|---|---|---|
| 🎣 **噱头** | 多少人愿意点进来 | 峰值在线（流量） |
| ⭐ **质量** | 内容扎不扎实 | 涨粉率、观众留存 |
| 🎪 **效果** | 情绪浓度、爆点、可乐性 | 打赏率、核心粉转化 |
| ⚠️ **风险** | 翻车概率 | 事故判定、黑粉、炎上 |

示例注入（数值示意）：

```text
💢 激情吐槽（🗣️杂谈）   噱头+2  效果+3  质量-1  风险+1
🎮 硬核攻略（🎮游戏）   质量+3  效果+1  噱头-1  风险-1
💋 色气打招呼（🎭演出）  噱头+2  效果+1  风险+1   男粉偏向
🥺 装可怜（🎭演出）     效果+3  打赏偏向++       风险+1（卖惨过头炎上）
🎤 突然清唱（🎤歌唱）   质量+1  效果+2  （歌唱力低 → 转为风险+2）
💻 整活特效（💻杂项）   噱头+2  质量+1  （杂项力低 → 技术事故）
```

**四轴不可兼得 + 槽位有限 = 每场都是取舍**：堆噱头牺牲质量——冲在线人数（短期钱）还是冲涨粉（长期盘），玩家自己选。

### 5.5 技能加成卡牌，而非直播类型

**卡牌效果 = 卡面基础注入 × 接口宽度系数 × 填充率功效 × (1 + 技能系数) × 素材连击修正**

- 每张卡以其**系别技能**为成长系数（杀戮尖塔"力量"式设计）：杂谈力高 → 所有杂谈系卡变强
- **策略性来源**：游戏素材不必然配游戏卡——《粪作猎人》+ 高杂谈力=吐槽回；+ 高演出力="色气恶魔陪玩烂游"；+ 高游戏力="烂游戏也要打出白金"。**同一素材，不同技能面板有不同最优解**，最优解取决于你的 build 和粉丝结构，不是查表
- **技能是长线投资方向**：练哪个系 = 决定卡池哪部分变强 → build 分流派
- 技能系数每级幅度：待定（基准候选：每级 +15%）

### 5.6 卡牌字段

```json
{

  "family": "talk",
  "tier": 1,
  "title": "激情吐槽",
  "description": "玩家可见的描述文字。",
  "leftSlots": [2, 4],      // 左接口（凹孔激活槽位），族 B = {2,4}
  "rightSlots": [2, 4],     // 右接口（凸柱激活槽位）

  "energyCost": 4,        // 演出预算消耗，T1=2 / T2=3~4 / T3=5~6（管"能不能用"）
  "materialRequire": [],  // 必需素材 tag：素材没有 → 本场不可用（UI 置灰，见 5.10）
  "materialBoost": [      // 素材 tag 命中 → 注入 ×1.3

```

**修饰卡字段**（无 leftSlots/rightSlots / axes，改为全局修正）：

```json

  "type": "modifier",
  "kind": "tone",           // tone 语气卡 / project 企划卡

  "description": "杂鱼~杂鱼~♡",
```

- `family`：技能系别（game/talk/song/act/tech）；`leftSlots/rightSlots`：接口激活槽位（1~4 的子集，∅=空）
- **效果数值只给代码读**；填充率、连击判定全部在代码侧
- **prompt 是 plain string 片段**；最终 prompt = 人设.prompt + 行为卡.prompt + 修饰卡.prompt + 素材.prompt + 状态快照（含卡序）拼接
- **prompt 工程尚未设计**：本阶段不预设任何措辞

### 5.7 收益结构（由四轴侧重涌现）

v0.2 的"涨粉卡/变现卡/事故卡"三分法不再是硬分类，而是四轴侧重的自然涌现：

- 质量轴侧重 → 涨粉卡（收益低、结构扩张，对冲固化）
- 效果轴侧重 → 变现卡（打赏流，压力消耗大）
- 风险轴侧重 → 事故卡（高风险高回报，含小概率"黑红"暴击，节目效果引擎）

### 5.8 EXP 与技能成长

**技能 EXP = 事件 + 实战**（没有"练习"动作——技能靠做事和直播变强）：

**① 事件 EXP**（占用时段的事件，普通事件每件 +10，高价值事件 +15~20）：

| 事件 | 系别 EXP |
|---|---|
| 打工 | 杂项力 +10（社会历练/抗压/设备操作） |
| 宅生活·打游戏 | 游戏力 +10 |
| 宅生活·看番/逛论坛/买谷子 | 杂谈力 +10（有得聊） |
| 宅生活·听歌/买音声 | 歌唱力 +10 |
| 陪朋友（约会/见面） | 杂谈力 +10（社交即练嘴） |
| 剧情/日常事件 | 按事件描述（鹿铃女仆店打工 → 演出力 +15 等） |

**② 实战 EXP（直播）**：本场每打出一张行为卡 → 该系别 EXP +5（**含素材锁定卡**——被锁定的游戏卡同样练游戏力）；修饰卡不计。

**③ 五级累计阈值**（Lv1 = 0 EXP 起）：

| 等级 | 累计 EXP | 增量 |
|---|---|---|
| Lv2 | 100 | +100 |
| Lv3 | 300 | +200 |
| Lv4 | 600 | +300 |
| Lv5 | 1000 | +400 |

曲线校验：90 天 × 3 时段 ≈ 270 个事件；每天"1 场直播（≈3 张同系卡 = +15）+ 1 次同系事件（+10）"≈ 25 EXP/天 → 单系 Lv5 需约 40 天专注；**五系全 Lv5（全能偶像 build）在 90 天周期内几乎不可能**——符合"成型最晚"的设定。

**主播等级与技能等级分离（两条成长线）：**

- **技能等级（1~5）**：走上述事件 + 实战 EXP，管**系别系数**（每级 +15%，见 5.5）与**高阶卡门槛**（见 5.5）
- **主播等级（1~10+）**：由**直播经营成果**（累计粉丝数/收益里程碑）驱动（具体曲线待测），管**演出预算上限**（见 5.9）、**修饰槽**（Lv3/8）、**卡牌解锁**（T2/T3 分层）

两套成长互不侵占："播得好"升主播等级，"做得久/做得多"升技能等级。

### 5.9 演出预算（卡牌成本与约束）

**为什么需要成本**：槽位有限（2~5）只限制卡数，不限制强度——若无成本，玩家永远塞"激情吐槽 + 无伤BOSS + 爆典"，最强牌组合唯一，构筑死亡。

**规则：**

- 每场直播有**演出预算**，**每场独立满额**（不做跨天恢复）
- 预算上限 = 主播等级基准：Lv1 = 10 … Lv10 = 20（具体曲线待测）
- 卡牌有 `energyCost`（T1 = 2 / T2 = 3~4 / T3 = 5~6）；**槽位 × 预算 = 双重约束**：槽位管卡数（素材决定），预算管强度（等级决定）——两个约束源彻底分开
- 拖卡进槽实时累加；超支 → 槽位边框变红，下一步置灰
- **压力 ≥ 80 时预算 -3**（"她今天状态撑不起大场面"）——单阈值，不做线性扣减
- **素材锁定卡不消耗预算**：它是题面不是玩家的选择，预算只结算玩家主动塞的卡（见 6.6）

**为什么每场满额（与"被否决的精力"的区别，见 4.5）：**

- 跨天恢复 = 跨日管理资源 = 与已否决的"每日精力"同类（时段已封顶行动量，再加就是双重管理）
- **跨天疲劳已有压力在管**：连续高强度 → 压力累积 → 逼你休息。预算再管疲劳就与压力功能重复（同"反应力并入杂谈力"的判据）
- 预算只做构筑约束（卡牌游戏的"法力上限"），压力只做跨天代价（肉鸽的"生命值"）——两层各管各的，无重叠

**压力成本保留为"后果"，不是"预算"**：卡牌的 `stressCost`（如激情吐槽 +10）不在预算里扣，而是打完这场后女主压力真实上升——**预算管"能不能用"，压力管"敢不敢用"**。想满配高强度 → 压力飞涨 → 播完必须去减压，否则坏结局线。

### 5.10 卡牌适配性（素材 tag 过滤）

**问题**：《动物森友会》素材上打出《无伤BOSS》——演出崩坏，LLM 还得在休闲游戏里硬编最终 BOSS。

**方案：素材 tag + 卡牌适配性两字段**

- 素材带 `tags`（见 6.6 / 6.7）
- 卡牌带：
  - `materialRequire`：必需 tag 列表——素材**没有** → 本场**不可用**（剧本编排 UI 置灰/隐藏）
  - `materialBoost`：加成 tag 列表——素材**有** → 注入 ×1.3
- 剧本编排步骤**只显示当前素材兼容的卡**，不兼容的折叠在"不兼容"区——**有效减少选卡时的信息量**（避免烟花缭乱）
- 副产品：LLM 永远不会被要求在没有 BOSS 的素材里捏造 BOSS——素材 prompt 与卡 prompt 的语义一致性由 tag 保证

**通用性 vs 适配性**：卡牌**通用优先**（大部分卡无 materialRequire，可配任意素材），仅强演出语义的卡设必需 tag——"无伤BOSS"卡适配 `boss_fight`，但"高能操作秀"只吃 `high_difficulty` 加成而不必需。适配是加分项不是门槛，门槛只留给会崩坏的卡。

### 5.11 修饰卡（两物种之二：语气卡 + 企划卡）

**为什么需要第二个物种**：有些效果**无法通过衔接卡实现**——"雌小鬼语气"不是节目单上的一个节目，而是**笼罩全场的滤镜**（把每一句台词的腔调都变成"杂鱼~杂鱼~♡"）。

| | 行为卡（70） | 修饰卡（20） |
|---|---|---|
| 本质 | 节目单上的**节目** | 全场的**滤镜** |
| 槽位接口 | 有（参与拼接） | **无**（不占节目槽） |
| 放置 | 剧本编排的节目槽 | 独立的**修饰槽**（主播等级 3 / 8 解锁） |
| 数值形态 | 四轴加法注入 | 全局乘法修正 + fanBias + 特殊效果 |
| prompt 形态 | 单拍演出指示 | **全场语气/规则片段**（注入每一拍快照） |

**语气卡 12（门槛按功能挂技能：腔调/人设 → 演出力；话术 → 杂谈力；声线 → 歌唱力）：**

| 卡名 | 效果 | 门槛 |
|---|---|---|
| **雌小鬼语气**（"杂鱼~杂鱼~♡"） | 效果轴/噱头轴注入 +30%（高能向节目），男粉++，打赏+，险 +15% | 演Lv2 |
| 大小姐语气（"哦呵呵呵"） | 质 +10% 效 +10%，女粉+ | 演Lv2 |
| 猫娘语尾（"~喵"） | 质量/留存向节目注入 +20%，核心粉+，**固化度增速+** | 演Lv2 |
| 中二病模式 | 噱头向节目注入 +20%，质 -10% | 演Lv2 |
| 病娇滤镜 | 效果向节目注入 +30%，核心粉++，黑粉+，险+ | 演Lv3 |

## 6. 素材系统

### 6.1 核心答案：一次性

素材**播一场烧一张**，库存里没有"剩余含量"：

- 每场直播消耗一张素材卡，用后即焚；再次使用需重新获得（重新进货 = 新实例）
- **为什么不是"有含量"（depth）**：预结算 + LLM 演绎架构下，同一素材重复播，LLM 只会产出高度相似的内容——我们既不为每个 depth 档位写 prompt，也看不到玩家本场打出的牌与直播中发生的事。重复 = 内容贬值，含量机制给不了差异化
- 一次性让**每场都是新题面**：素材供给量直接决定可播场次，素材成为真正的消耗品；内容差异来自不同素材的组合，而不是同一素材的深浅
- 素材消耗节奏变快 → 获取管道（6.3）供给频率需相应上调（待测试）

### 6.2 两种类型

| 类型 | 例子 | 经济角色 |
|---|---|---|
| 消耗型 | Sbeam 游戏、追新番、谷子开箱、论坛热梗 | 播一场即焚；对应游戏实况/歌回/杂谈/整活 |
| **商单型** | 游戏推广、恰饭广告（type: sponsor） | **保底金钱 + 锁定广告卡 + 满意度判定**（见 6.5）——钱和节目质量二选一的高压线 |

素材实例无消耗曲线：只有 `definition_id / instance_id`，没有含量/进度/新鲜度——用即删，不存在"陈旧素材"。

### 6.3 获取管道（稳定供给）

- **购买流（确定性）**：Sbeam 商店、周边店——钱的出口，防金钱溢出
- **白嫖/事件流（半随机）**：限免、朋友安利、论坛热梗、外出事件——时间的出口
- **轮换池**：商店固定上架 + 季节性活动轮换，保证后期供给
- **技能挂接**：知识面提高素材利用率——技能是素材的放大器
- 一次性化后供给频率上调：**每场直播烧一张**，库存余量应能支撑玩家"直播为主的运营路线"（数值待测）

### 6.4 素材即内容卡

素材与卡牌**共用同一套字段**（title / description / axes / combo / prompt），额外字段：`slots`、`lockedCards`。数据模型上只有一种东西：**内容卡**。

**素材的四轴修正与连击标签**（接入 7.3 结算）：

- 素材自带轴修正：垃圾游戏 → 吐槽类卡效果轴 ×2；公认神作 → 质量轴 +，但吐槽卡风险 ×2（炎上）
- 由此，素材迫使玩家按场调整卡组——不存在一套卡打天下

**待拍板**：素材 prompt 来源：核心素材手写保质感，其余 LLM 生成初稿 + 人工审核（是否接受混排）。

### 6.5 素材完整字段与 tag 系统

```json
{
  "id": "game_trash_hunter",
  "type": "consumable",      // consumable（消耗型）/ sponsor（商单型）
  "title": "《粪作猎人》",      // 素材名；仅作开播前的标题占位
  "description": "玩家可见描述。",
  "tags": ["game", "trash_game", "boss_fight", "action", "rage_bait"],
  "affinity": { "talk": 1.5, "game": 1.0, "act": 0.8 },  // 对系别的天然适配
  "axes": { "hook": 1, "quality": -1 },                    // 素材自带四轴修正
  "combo": [                                                 // 素材 × 卡 tag 的大额连击
    { "withCardTag": "rant", "impactMult": 2.0 },           // 垃圾游戏 × 吐槽 = 爆炸
    { "withCardTag": "hardcore", "riskMult": 2.0 }          // 垃圾游戏 × 硬核 = 炎上
  ],
  "prompt": "<string>"
}
```

- 卡牌过滤依据：`materialRequire` / `materialBoost` 与素材 `tags` 匹配（见 5.10）
- **素材 tag 与卡牌 tag 是同一套闭包**（卡牌 `tags` 字段引用的就是它）——两个系统共用词表，杜绝"对不上号"
- **直播标题 = 开播时 LLM 中途生成**（见 10.2 第 1 步）：素材名只作开播前的占位。既然素材由 LLM 生成（见 6.3"素材 prompt 来源"），再让 LLM 给素材配标题池，本质等于把标题生成挪到更早却看不到本场人设/卡组——中途生成可以按人设 + 节目单 + 主播状态微调

**素材即题面（v0.7 核心扩展）——槽位与锁定卡：**

```json
{
  "slots": 4,                 // 本场节目槽数量（素材的"厚度"，见 5.1）
  "lockedCards": [            // 锁定卡：素材自带，不来自玩家卡池
    { "cardId": "mat_boss_fight", "position": 3 },           // 严锁：固定槽位，不可拖出
    { "cardId": "mat_ending", "position": 4, "mode": "loose" } // 松锁变体：卡必须在"后半场"区间内
  ],
  "sponsor": {                // 商单型素材专属（type: "sponsor"）
    "money": 3000,            // 保底收益
    "satisfaction": { "qualityFloor": 5, "accidentPenalty": 0.5 } // 质量轴低于阈值或出事故 → 收益×0.5
  }
}
```

规则要点：

- **锁定卡由素材自带**（《BOSS战》《广告植入》《惊吓时刻》《开箱瞬间》是素材专属卡），不膨胀 90 张主卡池；素材即内容，锁定卡即素材的"题面零件"
- **锁定卡不消耗演出预算**、不可拖出（严锁）；松锁变体（`mode: "loose"`）允许卡在指定区间内任意槽——锁型本身是素材个性
- **素材一次性 → 无章节推进**：原 progressLocks（章节锁定卡）废除，锁定卡只有基础一档。每场是新素材，题面即本场唯一题面
- **商单型 = 钱和节目质量的高压线**：保底金钱 + 锁定烂接口广告卡（占用槽位、干扰链），本场质量轴过低或出事故 → 满意度↓ → 收益打折 + 叙事钩子（商单是青梅接的，她那边会说话）
- 解谜示例（《粪作猎人》，4 槽，槽 3 锁 B|B《BOSS战》）：题面 = 槽 2 的右接口必须喂 B 族、槽 4 的左接口要被 B 填——解法A（B 族顺流全链满血）vs 解法B（吃桥硬解或空接 ×0.8），同一题面不同卡池/技能 = 不同最优解

### 6.6 tag 闭包（素材与卡牌共用词表）

| 类 | tag |
|---|---|
| 内容领域 | `game`, `trash_game`, `masterpiece`, `casual`, `horror`, `story_rich`, `music`, `voice_acting`, `moe`, `otaku_culture` |
| 玩法特征 | `boss_fight`, `high_difficulty`, `hardcore`, `speedrun`, `multiplayer`, `rage_bait` |
| 话题特征 | `gossip`, `life_story`, `hot_topic`, `confession`, `rant` |

tag 闭包按需扩展；原则：**卡牌所需 tag 必须在闭包内**（新增 tag = 一次内容审查），防止 tag 通货膨胀。

## 7. 直播系统

### 7.1 三拍制（待测试）

演出结构：**开头 / 中间 / 结尾**。最终形态（每拍内容、长度、快进交互）需长期测试后定稿，当前不深入。

### 7.2 预结算架构（关键）

- **开播瞬间，代码先掷完整场结果**：四轴、产出、事故、粉丝变动全部由代码预结算
- **LLM 只是照既定结果演绎**——它不知道结果，只负责演出
- 演出**不反写核心数值**（纯装饰）；LLM 输出标签仅写回体验记忆与叙事层（下播日记、弹幕氛围）

由此得到的性质：

- **跳过/快进永远安全**：结算已存在，跳过演出 = 丢弃装饰、立刻结算，同时省 token
- **断网/失败有兜底**：数值不依赖 LLM

### 7.3 四轴结算管线

```text
① 基础盘   = 素材基础热度 × 粉丝基数
② 四轴累计 = Σ [ 卡牌注入 × 接口宽度系数 × 填充率功效 × (1 + 技能系数) ] + 素材轴修正
③ 产出换算（单轴对单产出的纯粹映射，可读性优先）：
   峰值在线 = 基础盘 × f(噱头)
   涨粉     = 峰值在线 × g(质量) × 路人转化率(受固化度压制，见 4.9)
   打赏     = 峰值在线 × h(效果) × 核心粉权重(0.3R + 0.6(M+W) + 1.6C − 0.5B)
   事故掷骰 = 风险轴 vs 压力修正 → 命中：黑粉↑ 炎上↑（小概率"黑红"：噱头暴涨）
④ 粉丝构成偏移 = Σ 卡牌 fanBias + 事故修正 → 归一化
```

- 是否让打赏小额吃质量（如 `打赏 = 效果为主 + 质量×0.2`）：待测试；当前基准为纯粹映射
- 三属性接入：压力高 → 全轴小幅降质 + 事故判定放宽；宅欲高 → 演出打折；孤独 >90% → 社交事故直接入池

**结算面板（下播后玩家所见）：**

```text
┌───────────── 📊 直播结算 ─────────────┐
│  峰值在线   2,847 人      (噱头 ↑↑)   │
│  新增粉丝   +312          (质量 ↑)    │
│  打赏收益   ¥1,840        (效果 ↑↑)   │
│  事故       无            (风险 12%)  │
│  粉丝构成   R32 M41 W15 C9 B3         │
│  合约进度   ¥18,400 / ¥50,000         │
└───────────────────────────────────────┘
```

### 7.4 流水线生成（表现层优化）

逐拍生成：玩家观看第 N 拍 AVG 演出时，后台生成第 N+1 拍——感知延迟被阅读时间吞掉。属于表现层优化，后期实现。

### 7.5 事前安排 / 事后处理

- **连麦朋友** = 准备阶段的一个行动（"今晚邀请网友连麦"），朋友状态/好感影响演出效果——朋友系统接入直播的唯一通道
- **黑粉/炎上无法在直播中救场** → 下播后的**舆情事件**：2~3 个菜单选项（发动态回应 / 冷处理 / 装死 / 道歉），影响粉丝构成与压力

## 10. 桌面 OS 界面

### 10.1 UI 总原则

1. **向导式，每步一件事**：多步骤流程用"步骤侧边栏 + 下一步"推进，玩家永远只面对一个问题；未完成时下一步置灰（门控），不会漏步骤
2. **界面各守其位**：女主三属性**不显示在直播软件内**——直播软件没有资格对她评头论足。三属性常驻于 OS 任务栏托盘（三个迷你条，随时可见）+ 日程界面大面板；直播软件后台读取数值用于结算与快照，但不显示
3. **不评头论足**：所有界面只提供信息（数值、接口族、风险值），不提供建议、警告、评分——判断是玩家的功课
4. **老玩家快捷**：开播向导默认沿用上次配置，可直达第三步一键开播

## 11. LLM 架构原则

1. **数值是真相，LLM 是表达**：核心结果代码预结算；LLM 输出标签仅写回体验记忆与叙事层
2. **标题先行，内容跟随**：入场动画期间先用短请求生成直播标题（人设 + 素材 + 节目单 + 主播状态 → 一行 ≤48 字）；标题回填后 UI 刷新、再发起 DSL 生成（DSL 的开场白围绕已定稿标题展开，标题与演出天然一致）。标题请求失败/超时（10s）→ 回退素材名，DSL 照常生成
3. **状态快照**：每节拍生成前给 LLM 一份快照 = **当前人设档位** + 熟练度 + 相关技能 + **三属性当前值** + 本场素材（含锁定卡）+ **卡组主导系别 + 卡序（节目单，含素材锁定卡，按序逐拍演绎）+ 修饰卡（全场语气/规则片段）** + 关系上下文 + 粉丝构成（观众氛围）
4. **三层记忆**：
   - 事实账本（代码存）：钱、合约进度、粉丝数、大事——LLM 无权改
   - 关系记忆（代码存）：谁是谁——朋友、榜一鹿铃（具名）、房管（半边界）
   - 体验记忆（LLM 摘要）：每场直播后压成摘要，下播日记/对话时注入
5. **成本控制**：按节拍短生成（1~2 秒/拍）；开场白缓存；弹幕 = 模板池 + LLM 点缀混合；跳过演出省 token；标题生成是极短请求，失败零成本回退

- **槽位接口系统**（取代 v0.4 情绪槽）：左右各 4 槽纯位置、零语义；**填充率 r = |R前 ∩ L后| ÷ |L后|**，四档功效（r=1 →×1.2 / ≥0.5 →×1.0 / >0 →×0.9 / 0 →×0.8+风险10%）；**基础注入按左接口宽度付费**（1槽×0.85 / 2槽×1.0 / 3槽×1.2 / 4槽×1.35）；右接口宽 = 桥梁卡（稀有），万能适配器（右 U）仅 2 张；开场卡左∅、收尾卡右∅；**全链满血奖励 ×1.1**；跨族 = 断链，接口族抱团 = 自然流派；"转场卡"概念废除
