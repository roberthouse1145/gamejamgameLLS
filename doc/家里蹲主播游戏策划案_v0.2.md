## 1. 游戏概述

### 1.1 一句话简介

玩家操作一个**桌面 OS 界面**，扮演被白富美青梅欺骗、签下 MCN 合约的**家里蹲宅女**，靠直播打工还债——否则将背上巨额违约金，从此沦为青梅的宠物。

### 1.2 核心体验

- 玩家操纵的是**女主角**，但她的性格底色很重，玩家的选择会被她的性格过滤——降低玩家的表演压力
- 女主是**家里蹲**：看番、打游戏、买谷子，这些宅生活本身就是直播素材（消费即生产）
- 喜剧外壳、压力内核（基调待最终确认）

### 1.3 设计支柱（五条分界线）

1. **非 Chat Game**：克制自由输入。大部分情况下玩家不做自由输入，而是通过**间接输入（日程安排、组卡、菜单选择）+ 游戏数值**驱动 LLM 演绎
2. **决策前置、演出放映**：直播中零决策、零打字；决策全部发生在**准备阶段**与**结算后**
3. **数值是真相，LLM 是表达**：核心结果由代码预结算，LLM 只负责把结果演出来
4. **消费即生产**：宅生活 → 素材 → 直播内容 → 收益 → 更好的宅生活
5. **粉丝是向量，朋友是角色**：粉丝只是数值与氛围，朋友才是故事（唯一具名例外：榜一 = 鹿铃，见 8.5）

## 2. 核心循环

```
宅生活（看番/打游戏/买谷子）
      ↓ 产出
     素材（内容含量）
      ↓
组卡开播（默认人设 + 素材实例 + 行为卡拼接 + 修饰卡加滤镜）
      ↓ 预结算 + LLM 演出
   直播放映（3~5 分钟游戏时间）
      ↓
   结算（在线/涨粉/打赏/事故/粉丝构成）
      ↓
下播处理（舆情菜单、朋友消息、下播日记）
      ↓
 金钱 → 还债/升级设备/买更多素材
 压力/宅欲/孤独 → 软约束下一天的安排
```

## 3. 时间结构与流程

### 3.1 90 天 / 6 期判定

- 总时长 **90 天**，每 **15 天**一次契约判定，共 **6 期**
- **判定失败** → 提前进入一般结局判定（最后 2~3 天为"结局周"）
- **撑到 90 天** → 进入好结局判定
- 好结局、一般结局均为**多结局**

### 3.2 每日 3 时段

- 每日 **上午 / 下午 / 晚上** 3 个时段，每时段一次行动
- 行动类型：打工（金钱）/ 宅生活（素材）/ 陪朋友（关系+减压力+减孤独）/ 直播 / 休息（减压力）
- 直播频次由玩家自选，不做硬性排班——约束来自数值而非规则（见 3.3）

### 3.3 软约束原则

- **直播频次由玩家自选**，不做硬性排班
- 约束来自数值而非规则：**三属性（压力/宅欲/孤独）+ 素材含量**
- **压力过满 → 坏结局线；宅欲过满 → 摆烂；孤独过满 → 社交事故**

## 4. 数值系统

### 4.1 分类总则：属性 / 资源 / 成长 / 关系

| 类别 | 内容 | 说明 |
|---|---|---|
| **属性**（女主状态，0~100，波动、阈值、喂 LLM） | 压力、宅欲、孤独 | 见 4.2 |
| **资源**（非属性） | 金钱（货币）、时间（3 时段）、素材含量、演出预算（单场卡牌强度上限，每场满额，见 5.9）、热度/收益/粉丝构成/炎上（跨场） | 金钱就是金钱，不是属性 |
| **成长**（非属性） | 五维技能、人设熟练度/固化度、主播等级/卡槽、知识面 | 长期积累 |
| **关系**（非属性） | 各朋友的好感、信任、依赖 | 各自独立 |

### 4.2 三属性（常驻可见条 ×3，黄油式驱力）

| 属性 | 涨的来源 | 消解方式 | 高了会怎样 |
|---|---|---|---|
| **压力** | 直播、打工、炎上、债务、判定临近 | 宅生活、陪朋友、休息 | >60% 演出降质 / >80% 摆烂 / **100% = 坏结局** |
| **宅欲** | 被迫做"正事/表演"（打工、直播、陪人） | 宅生活（看番/游戏/买谷） | >70% 心不在焉、演出打折 / >90% 摆烂（"下周再努力吧"） |
| **孤独** | 宅生活（隔绝）、**直播（单向关注不填坑）** | 陪朋友 | >70% 下播日记变丧 / >90% 社交事故（直播中绷不住人设） |

**关键洞察（情感内核）**：直播**同时涨宅欲和孤独**——她被迫当众表演，但观众是单向关注，没有人真的认识她。合约逼她做的是唯一"喂不饱她、反而饿死她"的工作。

### 4.3 阈值与释放事件（黄油式手感）

- **满值释放事件**：
  - 宅欲满 → 深夜爆肝游戏事件（时间损失 + 素材爆率）
  - 孤独满 → 半夜给青梅发消息（关系事件，露出破绽）
- **交叉作用**：
  - 压力高时，宅生活回宅欲更快（报复性消费）
  - 宅欲高时，直播扣压力更多（被迫营业更痛）

### 4.4 防刷法检验（属性的存在意义）

| 刷法 | 后果 |
|---|---|
| 只直播 | 三属性全涨 → 演出崩、事故、摆烂 |
| 只打工 | 宅欲↑↑ → 摆烂；且合约进度停滞 → 判定失败 |
| 只宅生活 | 孤独↑↑ → 社交事故；且没钱 → 判定失败 |
| 只陪朋友 | 判定失败（自然结果） |

素材含量与合约判定是天然刹车——不需要精力类假刹车。

### 4.5 被否决的数值及理由

| 数值 | 否决理由 |
|---|---|
| 精力 | 3 时段已封顶每日行动次数，精力是第二根行动条，冗余 |
| 快乐值 | 宅生活本身已被机制奖励（素材 + 灵感 buff），再立一条即重复 |
| 激情值/动力 | 用"压力高时休息效果打折、下播日记语气变丧"表达，不做第二条压力条 |
| 健康条 | 用压力慢性效果表达，上限管理代替第二根条 |

（孤独曾被否决，后因承担"防刷法 + 朋友系统驱动"的双重职责而被采纳为属性。）

> **"精力"被否决 ≠ "演出预算"被否决**：被否决的精力是**每日行动条**（与 3 时段重复，见上表）；演出预算是**单场牌组强度上限**（构筑约束，见 5.9），作用域完全不同——前者管"一天能做几件事"，后者管"一场能编多重的节目"。

### 4.6 五维技能（成长数值核心）

**五个互不包含的维度，对应五个身体部位/能力层：手 / 嘴 / 声 / 演 / 技。**

| 维度 | 一眼即懂 | 边界（不含什么） | 底层 |
|---|---|---|---|
| 🎮 **游戏力** | 玩游戏的水平（操作、通关、理解） | 不含说话、不含搞笑 | 手 |
| 🗣️ **杂谈力** | 会聊天、会接梗、能救场；**含接弹幕、回 SC、怼黑粉** | 不含游戏操作、不含扮演 | 嘴 |
| 🎤 **歌唱力** | 唱歌、音准、声线质感（歌回 / ASMR / 电台） | 不含演技 | 声 |
| 🎭 **演出力** | 演人设、夹嗓子、卖萌、营业——"皮套后面的表演" | 不含真本事、不含技术 | 演 |
| 💻 **杂项力** | 设备、OBS、调音、剪辑切片等台后技术 | 不含任何台前能力 | 技 |

**设计决定：**

- 曾设第六维"反应力"（接弹幕/应对黑粉），因与杂谈力同为"靠嘴输出"、在数值上作用于同一位置而**并入杂谈力**——两个技能解释同一场直播就是冗余
- **技能不加成"直播类型"，而是加成对应系别的卡牌**（见 5.5）——避免"一维服务一类直播"的查表化，保住组卡策略性
- 技能第二作用：**高级卡的解锁门槛**（如演出力 Lv.3 解锁《瞬间变声卖萌》）
- 升级方式：完成直播获得主播 EXP → 主播升级 → 获得公共成长点 → 玩家自由投资五系技能；不设置独立"练习"行动或分系技能 EXP
- **知识面**（深度/广度，素材利用率放大器）保留为独立成长值，不占五维（是否并入杂项力：待定）

### 4.7 其他长期数值

- **人设数值**（每个档位一套）：熟练度、固化度
  - 长期扮演同一档位 → 熟练度↑（演出基础倍率↑），但同时固化度↑（新粉转化率↓）
  - 人设档位 ≠ 人设数值：档位是"选择演什么"，数值是"演得多熟/观众多固化"
- **关系**：与每个朋友的好感、信任、依赖（各自独立）

### 4.8 跨场数值（不上常驻条）

- **粉丝构成向量**（见 4.9）
- **炎上值**：跨场累计，压力源放大器
- **契约进度**：债务余额、6 期判定完成情况

### 4.9 粉丝构成向量（五类互斥）

**结构**：`路人 R / 男粉 M / 女粉 W / 核心粉 C / 黑粉 B`，归一化百分比：R+M+W+C+B = 100%。路人无性别；核心粉、黑粉从男女粉转化而来。

**每场直播后的变动流程：**

1. **基础扰动 Δ** = Σ(行为卡 fanBias) + 素材 affinity 修正 + 事故修正（事故 → B↑、R↓）
2. **新增路人** = 峰值在线 × 转化率；转化率 = base × (1 − 0.8 × (C+B))
   - **核心粉与黑粉占比越高，新粉越难流入 —— "观众固化"的数值落地**
3. **路人 → 男女粉**：按质量轴留存系数（见 7.3）
4. **男女粉 → 核心粉**：打赏/舰长事件概率转化（核心粉 = 金主）
5. **黑粉**：增 = 炎上量 × 黑化系数；每场自然衰减 10%（淡出，但节奏事件可复活）
6. **归一化**

**反哺（让向量真正影响决策）：**

- **变现**：打赏权重 = (0.3R + 0.6(M+W) + 1.6C − 0.5B)——核心粉是金主，"转化核心粉"是经营目标
- **破圈**：新粉转化率 ∝ R 占比。长期演同一人设 → 结构偏科 → 破圈停滞
- **舆论**：B > 15% → 炎上概率翻倍、事故放大，并进入状态快照（LLM 演"黑粉蠢动的弹幕氛围"）
- **换人设成本**：切换档位时，M/W 结构 ×0.8（脱粉 20%），且 C×0.3 转化为 B（脱粉回踩）
  - 这收紧了核心张力：**专精 → 熟练度↑、变现↑，但固化 → 增长停滞；多元 → 增长快，但变现差**
- **演出语境**：构成向量作为状态快照的一部分给 LLM，LLM 只演"氛围"，不演有名有姓的粉丝个体——**唯一例外：榜一鹿铃**（见 8.5，具名角色，单独人物卡）

**显示简化**：一根五段条形图 + 总粉丝数 + 一句提示（如"黑粉扎堆"/"观众结构固化"），玩家看趋势，不读数字。

## 5. 卡牌系统

### 5.1 总览（90 张 = 行为卡 70 + 修饰卡 20）

- **两个物种**：
  - **行为卡（70）**：节目单上的"节目"，有情绪槽、参与拼接，按**五技能系别**划分：🎮 游戏 14 / 🗣️ 杂谈 16 / 🎤 歌唱 12 / 🎭 演出 14 / 💻 杂项 14（各系含开场卡 / 中坚卡 / 收尾卡 / 高阶卡）
    - v0.3 的"方向树"（游戏/ASMR/杂谈/唱见/整活）并入五系：ASMR、唱见 → 歌唱系；整活 → 演出系或杂项系
  - **修饰卡（20）**：全场的"滤镜"，无情绪槽、不占节目槽，分**语气卡 12（腔调/声线/话术）+ 企划卡 8（本场规则）**（见 5.11）
- 解锁分层：基础卡（前 15 天）/ 进阶卡（30 天后）/ 王牌卡（60 天后）
- **槽位**：节目槽初始 2，每升 2 级 +1，上限 5~6；**修饰槽**：主播等级 3 解锁第 1 个，等级 8 解锁第 2 个（与节目槽完全独立，见 5.11）
- **分区取消**：玩家不选"直播分区"——素材已隐含内容类型（游戏素材=游戏回，游戏回忆=杂谈回），本场"是什么直播"由素材 + 卡组主导系别自然涌现，LLM 按主导系别演绎。选分区是多此一举
- 分布表 / 技能树 / Build 原型见 5.12 / 5.13 / 5.14

### 5.2 卡面双标识（两套标识，不混淆）

每张卡有两套彼此独立的标识，用不同视觉语言：

| 标识 | 视觉 | 作用 |
|---|---|---|
| **技能系别** | 图标（🎮🗣️🎤🎭💻） | 决定这张卡吃哪个技能的加成（见 5.5） |
| **情绪槽** | 卡牌**左右两端的颜色**（渲染为真实拼图块：左端凹槽 = 入口，右端凸槽 = 出口） | 决定卡与卡的连接关系（见 5.3） |

卡面信息分层：正面只放 系别图标 + 双端槽色 + 四轴注入；详情（连击、fanBias、压力消耗、解锁条件）悬停展开——控制决策负担。

```text
┌─────────────────────┐
│ 🔴→  激情吐槽  →🔴  │   ← 左端入口槽 / 右端出口槽
│ 🗣️ 杂谈系 · Tier 1  │
│ 噱头+2 效果+3 质量-1 │
│ 风险+1              │
└─────────────────────┘
```

### 5.3 情绪槽系统（拼图连接）

**每张卡可有多个入口槽（左）和多个出口槽（右）**，代表"这张卡可以承接哪些情绪、可以输出哪些情绪"。四种颜色各自占据一个固定候选高度；同一张卡可同时在多个高度绘制凹槽或凸槽。4 色 + 空槽：

**视觉语言 = 真实拼图块**：卡牌左端按入口集合画出一个或多个**凹槽**，右端按出口集合画出一个或多个**凸槽**，凹凸形状一眼可见——**开场卡只有右侧凸槽**（左端平齐，天然起点），**收尾卡只有左侧凹槽**（右端平齐，天然结束）。槽色涂在对应凹凸形状上：玩家扫一眼卡边缘的形状 + 颜色就知道能不能接、接得顺不顺，无需读文字。

| 槽色 | 情绪 | 直播语境 |
|---|---|---|
| 🔴 **热烈** | 激昂、兴奋、色气、整活 | 高能时刻，观众刷"草" |
| 🔵 **冷静** | 分析、攻略、正经讲解 | 理性内容，观众认真听 |
| 🟡 **温和** | 闲聊、陪伴、日常、治愈 | 低压时段，观众放松 |
| 🟣 **丧气** | 吐槽、抱怨、emo、摆烂 | 负面情绪，观众共鸣或劝慰 |
| ⚪ **空槽** | — | 开场卡的入口（接任意）、收尾卡的出口（无后续） |

**匹配规则（梯度奖励，不硬性禁止）：**

| 连接情况 | 判定 | 效果 |
|---|---|---|
| 两侧集合存在同色 | **完美匹配** | 后一张卡四轴注入 ×1.2 |
| 两侧所有可选组合均为 🔴 热烈 ↔ 🟣 丧气 | **冲突（唯一的死敌对）** | 后一张卡注入 ×0.8，且风险轴 +15%（"人设割裂"） |
| 其余任意组合 | **兼容** | 无加成无惩罚（🟡 温和是万金油） |

一句话规则：**同色完美，热烈丧气互为死敌，其余随便接。**玩家 30 秒学会。

**匹配只看"接缝"，不看卡自身的内外色**：

- 匹配判定只发生在**两张卡的接缝处**（前一张出口 vs 后一张入口）
- 一张卡**自身的入口≠出口**（如 🔴→🟣《卡关暴走》）不是冲突——那是这张卡**设计好的情绪转折**，是合法的**转场卡**：想从热烈安全过渡到丧气，要么持有转场卡（稀缺资源），要么硬接吃惩罚。转场卡 = 拼图的"异形接口件"，是独立战略子类（分布见 5.12，共 21 张）

**结构规则：**

- 开场卡：入口 ⚪（接任意；视觉：仅右侧凸槽，左端平齐），各系都有自己的开场卡（正经开场=🔵出口，色气打招呼=🔴出口）
- 收尾卡：出口 ⚪（视觉：仅左侧凹槽，右端平齐）。**非必需**（初始 2 槽放不下）；价值是收尾奖励（观众留存↑ / 压力回复）——中期槽位多了以后自然进入构筑
- 完全不匹配也可以塞：惩罚是效果打折 + 风险，不是禁止——赌狗保留操作空间
- 全链完美匹配的额外奖励（"行云流水"全场 buff）：待测试，防止过度奖励导致构筑单一化

**示例 build：**

```text
A 热烈连击（冲在线+打赏）：⚪→🔴打招呼 ▸ 🔴→🔴激情吐槽 ▸ 🔴→⚪整活收尾   完美×2
B 冷静质量流（冲涨粉）：  ⚪→🔵正经开场 ▸ 🔵→🔵硬核攻略 ▸ 🔵→⚪温和收尾  完美×2
C 混搭冒险（赌狗）：      ⚪→🔴打招呼 ▸ 🔴→🟣突然emo ▸ 🟣→🔴强行整活救场
                          接缝①：打招呼🔴 → emo🔴 = 完美匹配（emo 自身 🔴→🟣 是转场卡，合法）
                          接缝②：emo🟣 → 强行整活🔴 = 冲突 ×0.8，风险 +15%
                          想吃🟣核心粉卡又不想牺牲🔴起手 → 持有 🔴→🟣 转场卡是唯一无损解法
```

**情绪流 = LLM 的情绪曲线脚本**：卡序的槽色序列（如 🔴→🔴→🟣→🔴）天然描述了本场直播的情绪起伏，直接进入状态快照——LLM 按这条曲线演绎节拍衔接（转折生硬处正是"割裂感"的演出素材）。卡牌系统与演出系统由此打通。

**UI 原则——不评头论足**：卡面与槽位只显示颜色和数值，引擎**不弹**"⚠️ 不匹配警告"或"💡 建议换卡"。匹配判断是玩家自己的功课，策略游戏不对玩家的构筑指手画脚。

### 5.4 四轴注入（卡牌的作用目标）

一场直播的中间结算层是**四轴**，每张卡对四轴的注入方向不同——这是卡与卡的真正区别：

| 轴 | 含义 | 换算去向 |
|---|---|---|
| 🎣 **噱头** | 多少人愿意点进来 | 峰值在线（流量） |
| ⭐ **质量** | 内容扎不扎实 | 涨粉率、观众留存 |
| 🎪 **效果** | 情绪浓度、爆点、可乐性 | 打赏率、核心粉转化 |
| ⚠️ **风险** | 翻车概率 | 事故判定、黑粉、炎上 |

示例注入（数值示意）：

```text
💢 激情吐槽（🗣️杂谈）   噱头+2  效果+3  质量-1  风险+1
🎮 硬核攻略（🎮游戏）   质量+3  效果+1  噱头-1  风险-1
💋 色气打招呼（🎭演出）  噱头+2  效果+1  风险+1   男粉偏向
🥺 装可怜（🎭演出）     效果+3  打赏偏向++       风险+1（卖惨过头炎上）
🎤 突然清唱（🎤歌唱）   质量+1  效果+2  （歌唱力低 → 转为风险+2）
💻 整活特效（💻杂项）   噱头+2  质量+1  （杂项力低 → 技术事故）
```

**四轴不可兼得 + 槽位有限 = 每场都是取舍**：堆噱头牺牲质量——冲在线人数（短期钱）还是冲涨粉（长期盘），玩家自己选。

### 5.5 技能加成卡牌，而非直播类型

**卡牌效果 = 卡面基础注入 × (1 + 技能系数) × 情绪匹配修正 × 素材连击修正**

- 每张卡以其**系别技能**为成长系数（杀戮尖塔"力量"式设计）：杂谈力高 → 所有杂谈系卡变强
- **策略性来源**：游戏素材不必然配游戏卡——《粪作猎人》+ 高杂谈力=吐槽回；+ 高演出力="色气恶魔陪玩烂游"；+ 高游戏力="烂游戏也要打出白金"。**同一素材，不同技能面板有不同最优解**，最优解取决于你的 build 和粉丝结构，不是查表
- **技能是长线投资方向**：练哪个系 = 决定卡池哪部分变强 → build 分流派
- 技能系数每级幅度：待定（基准候选：每级 +15%）


- `family`：技能系别（game/talk/song/act/tech）；`moodInputs/moodOutputs`：情绪槽数组（hot/calm/warm/gloom）；空入口数组表示开场卡，空出口数组表示收尾卡
- **效果数值只给代码读**；情绪匹配、连击判定全部在代码侧
- **prompt 是 plain string 片段**；最终 prompt = 人设.prompt + 行为卡.prompt + 修饰卡.prompt + 素材.prompt + 状态快照（含情绪流序列）拼接
- **prompt 工程尚未设计**：本阶段不预设任何措辞

### 5.7 收益结构（由四轴侧重涌现）

v0.2 的"涨粉卡/变现卡/事故卡"三分法不再是硬分类，而是四轴侧重的自然涌现：

- 质量轴侧重 → 涨粉卡（收益低、结构扩张，对冲固化）
- 效果轴侧重 → 变现卡（打赏流，压力消耗大）
- 风险轴侧重 → 事故卡（高风险高回报，含小概率"黑红"暴击，节目效果引擎）

### 5.8 EXP 与解锁

- 每完成一场直播获得 **50 主播 EXP**；Lv1~10 累计阈值为 `0/100/250/450/700/1000/1400/1900/2500/3200`
- 主播每升一级获得 **1 公共成长点**，由玩家自由投入游戏 / 杂谈 / 歌唱 / 演出 / 杂项五条线性技能分支
- 主播等级负责 Tier 与节目槽开放；部分高阶卡同时要求对应技能等级（见 5.5）

### 5.9 演出预算（卡牌成本与约束）

**为什么需要成本**：槽位有限（2~5）只限制卡数，不限制强度——若无成本，玩家永远塞"激情吐槽 + 无伤BOSS + 爆典"，最强牌组合唯一，构筑死亡。

**规则：**

- 每场直播有**演出预算**，**每场独立满额**（不做跨天恢复）
- 预算上限 = 主播等级基准：Lv1 = 10 … Lv10 = 20（具体曲线待测）
- 卡牌有 `energyCost`（T1 = 2 / T2 = 3~4 / T3 = 5~6）；**槽位 × 预算 = 双重约束**：槽位管卡数，预算管强度
- 拖卡进槽实时累加；超支 → 槽位边框变红，下一步置灰
- **压力 ≥ 80 时预算 -3**（"她今天状态撑不起大场面"）——单阈值，不做线性扣减

**为什么每场满额（与"被否决的精力"的区别，见 4.5）：**

- 跨天恢复 = 跨日管理资源 = 与已否决的"每日精力"同类（时段已封顶行动量，再加就是双重管理）
- **跨天疲劳已有压力在管**：连续高强度 → 压力累积 → 逼你休息。预算再管疲劳就与压力功能重复（同"反应力并入杂谈力"的判据）
- 预算只做构筑约束（卡牌游戏的"法力上限"），压力只做跨天代价（肉鸽的"生命值"）——两层各管各的，无重叠

**压力成本保留为"后果"，不是"预算"**：卡牌的 `stressCost`（如激情吐槽 +10）不在预算里扣，而是打完这场后女主压力真实上升——**预算管"能不能用"，压力管"敢不敢用"**。想满配高强度 → 压力飞涨 → 播完必须去减压，否则坏结局线。

### 5.10 卡牌适配性（素材 tag 过滤）

**问题**：《动物森友会》素材上打出《无伤BOSS》——演出崩坏，LLM 还得在休闲游戏里硬编最终 BOSS。

**方案：素材 tag + 卡牌适配性两字段**

- 素材带 `tags`（见 6.6 / 6.7）
- 卡牌带：
  - `materialRequire`：必需 tag 列表——素材**没有** → 本场**不可用**（剧本编排 UI 置灰/隐藏）
  - `materialBoost`：加成 tag 列表——素材**有** → 注入 ×1.3
- 剧本编排步骤**只显示当前素材兼容的卡**，不兼容的折叠在"不兼容"区——**有效减少选卡时的信息量**（避免烟花缭乱）
- 副产品：LLM 永远不会被要求在没有 BOSS 的素材里捏造 BOSS——素材 prompt 与卡 prompt 的语义一致性由 tag 保证

**通用性 vs 适配性**：卡牌**通用优先**（大部分卡无 materialRequire，可配任意素材），仅强演出语义的卡设必需 tag——"无伤BOSS"卡适配 `boss_fight`，但"高能操作秀"只吃 `high_difficulty` 加成而不必需。适配是加分项不是门槛，门槛只留给会崩坏的卡。

### 5.11 修饰卡（两物种之二：语气卡 + 企划卡）

## 6. 素材系统

### 6.1 核心答案：有含量

素材**既不是一次性，也不是无限**，而是"**有含量（depth）**"：

- 含量是资源池。如一款游戏含量 4；每场直播按类型消耗：杂谈耗 0.5~1，游戏实况耗 1~2
- 含量耗尽 → 素材变"陈旧"：还能引用，但直播质量下降（观众："主播又在水"）

### 6.2 三个属性

| 属性 | 作用 |
|---|---|
| 含量 depth | 还能喂几场直播 |
| 进度 progress | 连续型素材的进度指针；每次游戏实况推进一章 |
| 衰减 freshness | 首发热度加成随场次递减；旧素材变"情怀素材"（倍率低、核心粉偏好高） |

**关于重复利用与 LLM 发挥**：重复的根源不是"用了第二次"，而是"没有新输入"。进度 + 上一场摘要（从体验记忆取）= 新输入 → 系列直播反而越播越有味道（callback："上次卡墙里那只 BOSS"）。

### 6.3 两种类型

| 类型 | 例子 | 经济角色 |
|---|---|---|
| 连续型 | Sbeam 游戏、追新番（带进度+含量） | 贵、高价值、需投入时间；对应游戏实况/歌回企划 |
| 消耗型 | 谷子开箱、限时活动、论坛热梗 | 便宜、即时、一次性；对应杂谈/整活 |

### 6.4 获取管道（稳定供给）

- **购买流（确定性）**：Sbeam 商店、周边店——钱的出口，防金钱溢出
- **白嫖/事件流（半随机）**：限免、朋友安利、论坛热梗、外出事件——时间的出口
- **轮换池**：商店固定上架 + 季节性活动轮换，保证后期供给
- **技能挂接**：知识面提高素材利用率——技能是素材的放大器

### 6.5 素材与卡牌共享内容协议，但不是同一种物品

素材与卡牌继承同一个公共内容基类（稳定 ID / title / description / Texture / tags / prompt），并使用同一套 tag 闭包；但二者是**独立 Resource 类型、独立库存、独立 UI**。卡牌进入节目单或修饰槽；素材以实例形式被第一步选择，实例各自维护 `depth / progress / freshness / useCount`，不进入玩家牌库。

**素材的四轴修正与连击标签**（接入 7.3 结算）：

- 素材自带轴修正：垃圾游戏 → 吐槽类卡效果轴 ×2；公认神作 → 质量轴 +，但吐槽卡风险 ×2（炎上）
- 由此，素材迫使玩家按场调整卡组——不存在一套卡打天下

**待拍板**：① 含量粒度按"场次"计（每场固定耗 1~2 格）是否够；② 素材 prompt 来源：核心素材手写保质感，其余 LLM 生成初稿 + 人工审核（是否接受混排）。

### 6.6 素材完整字段与 tag 系统

```json
{
  "id": "game_trash_hunter",
  "type": "continuous",      // continuous（连续型）/ consumable（消耗型）
  "title": "《粪作猎人》",
  "description": "玩家可见描述。",
  "initialDepth": 4,         // 定义侧：新实例初始含量
  "maxProgress": 4,          // 定义侧：连续型最大进度
  "freshnessDecay": 0.2,     // 定义侧：每场新鲜度衰减
  "tags": ["game", "trash_game", "boss_fight", "action", "rage_bait"],
  "affinity": { "talk": 1.5, "game": 1.0, "act": 0.8 },  // 对系别的天然适配
  "axes": { "hook": 1, "quality": -1 },                    // 素材自带四轴修正
  "combo": [                                                 // 素材 × 卡 tag 的大额连击
    { "withCardTag": "rant", "impactMult": 2.0 },           // 垃圾游戏 × 吐槽 = 爆炸
    { "withCardTag": "hardcore", "riskMult": 2.0 }          // 垃圾游戏 × 硬核 = 炎上
  ],
  "prompt": "<string>"
}
```

- 卡牌过滤依据：`materialRequire` / `materialBoost` 与素材 `tags` 匹配（见 5.10）
- **素材 tag 与卡牌 tag 是同一套闭包**（卡牌 `tags` 字段引用的就是它）——两个系统共用词表，杜绝"对不上号"

### 6.7 tag 闭包（素材与卡牌共用词表）

| 类 | tag |
|---|---|
| 内容领域 | `game`, `trash_game`, `masterpiece`, `casual`, `horror`, `story_rich`, `music`, `voice_acting`, `moe`, `otaku_culture` |
| 玩法特征 | `boss_fight`, `high_difficulty`, `hardcore`, `speedrun`, `multiplayer`, `rage_bait` |
| 话题特征 | `gossip`, `life_story`, `hot_topic`, `confession`, `rant` |

tag 闭包按需扩展；原则：**卡牌所需 tag 必须在闭包内**（新增 tag = 一次内容审查），防止 tag 通货膨胀。

## 7. 直播系统

### 7.1 三拍制（待测试）

演出结构：**开头 / 中间 / 结尾**。最终形态（每拍内容、长度、快进交互）需长期测试后定稿，当前不深入。

### 7.2 预结算架构（关键）

- **开播瞬间，代码先掷完整场结果**：四轴、产出、事故、粉丝变动全部由代码预结算
- **LLM 只是照既定结果演绎**——它不知道结果，只负责演出
- 演出**不反写核心数值**（纯装饰）；LLM 输出标签仅写回体验记忆与叙事层（下播日记、弹幕氛围）

由此得到的性质：

- **跳过/快进永远安全**：结算已存在，跳过演出 = 丢弃装饰、立刻结算，同时省 token
- **断网/失败有兜底**：数值不依赖 LLM

### 7.3 四轴结算管线

```text
① 基础盘   = 素材基础热度 × 粉丝基数 × 新鲜度 freshness
② 四轴累计 = Σ [ 卡牌注入 × (1 + 技能系数) × 情绪匹配修正 ] + 素材轴修正
③ 产出换算（单轴对单产出的纯粹映射，可读性优先）：
   峰值在线 = 基础盘 × f(噱头)
   涨粉     = 峰值在线 × g(质量) × 路人转化率(受固化度压制，见 4.9)
   打赏     = 峰值在线 × h(效果) × 核心粉权重(0.3R + 0.6(M+W) + 1.6C − 0.5B)
   事故掷骰 = 风险轴 vs 压力修正 → 命中：黑粉↑ 炎上↑（小概率"黑红"：噱头暴涨）
④ 粉丝构成偏移 = Σ 卡牌 fanBias + 事故修正 → 归一化
```

- 是否让打赏小额吃质量（如 `打赏 = 效果为主 + 质量×0.2`）：待测试；当前基准为纯粹映射
- 三属性接入：压力高 → 全轴小幅降质 + 事故判定放宽；宅欲高 → 演出打折；孤独 >90% → 社交事故直接入池

**结算面板（下播后玩家所见）：**

```text
┌───────────── 📊 直播结算 ─────────────┐
│  峰值在线   2,847 人      (噱头 ↑↑)   │
│  新增粉丝   +312          (质量 ↑)    │
│  打赏收益   ¥1,840        (效果 ↑↑)   │
│  事故       无            (风险 12%)  │
│  粉丝构成   R32 M41 W15 C9 B3         │
│  合约进度   ¥18,400 / ¥50,000         │
└───────────────────────────────────────┘
```

### 7.4 流水线生成（表现层优化）

逐拍生成：玩家观看第 N 拍 AVG 演出时，后台生成第 N+1 拍——感知延迟被阅读时间吞掉。属于表现层优化，后期实现。

### 7.5 事前安排 / 事后处理

- **连麦朋友** = 准备阶段的一个行动（"今晚邀请网友连麦"），朋友状态/好感影响演出效果——朋友系统接入直播的唯一通道
- **黑粉/炎上无法在直播中救场** → 下播后的**舆情事件**：2~3 个菜单选项（发动态回应 / 冷处理 / 装死 / 道歉），影响粉丝构成与压力

## 10. 桌面 OS 界面

### 10.1 UI 总原则

1. **向导式，每步一件事**：多步骤流程用"步骤侧边栏 + 下一步"推进，玩家永远只面对一个问题；未完成时下一步置灰（门控），不会漏步骤
2. **界面各守其位**：女主三属性**不显示在直播软件内**——直播软件没有资格对她评头论足。三属性常驻于 OS 任务栏托盘（三个迷你条，随时可见）+ 日程界面大面板；直播软件后台读取数值用于结算与快照，但不显示
3. **不评头论足**：所有界面只提供信息（数值、槽色、风险值），不提供建议、警告、评分——判断是玩家的功课

## 11. LLM 架构原则

1. **数值是真相，LLM 是表达**：核心结果代码预结算；LLM 输出标签仅写回体验记忆与叙事层
2. **状态快照**：每节拍生成前给 LLM 一份快照 = 人设档位 + 熟练度 + 相关技能 + **三属性当前值** + 本场素材 + **卡组主导系别 + 情绪流序列（本场情绪曲线脚本）+ 修饰卡（全场语气/规则片段）** + 关系上下文 + 粉丝构成（观众氛围）
3. **三层记忆**：
   - 事实账本（代码存）：钱、合约进度、粉丝数、大事——LLM 无权改
   - 关系记忆（代码存）：谁是谁——朋友、榜一鹿铃（具名）、房管（半边界）
   - 体验记忆（LLM 摘要）：每场直播后压成摘要，下播日记/对话时注入
4. **成本控制**：按节拍短生成（1~2 秒/拍）；开场白缓存；弹幕 = 模板池 + LLM 点缀混合；跳过演出省 token

## 14. 已确认 / 待定项

### 已确认

- 无自由输入、无直播中决策；决策在准备阶段与结算后
- 90 天 / 6 期判定 / 每日 3 时段（每时段一次行动）
- 直播频次玩家自选，三属性 + 素材含量软约束（压力过满 = 坏结局线；宅欲过满 = 摆烂；孤独过满 = 社交事故）
- **三属性（压力/宅欲/孤独）**；金钱是资源不是属性；砍精力/快乐/激情/健康；宅欲低的代价暂不做
- **五维技能：游戏力/杂谈力/歌唱力/演出力/杂项力**（手/嘴/声/演/技）；反应力并入杂谈力；技能加成卡牌而非直播类型
- **取消直播分区**：内容类型由素材 + 卡组主导系别涌现
- **四轴中间层（噱头/质量/效果/风险）**：噱头→在线、质量→涨粉、效果→打赏、风险→事故；单轴对单产出纯粹映射为基准
- **情绪槽系统**：4 色（热烈/冷静/温和/丧气）+ 空槽；每张卡可有多个入口与多个出口，同色集合有交集即完美 ×1.2、热烈↔丧气且无其他兼容组合时 ×0.8+风险 15%、其余兼容；不匹配可塞（梯度惩罚非禁止）；**匹配只看接缝，卡自身入口集合≠出口集合 = 合法转场卡**；**卡牌渲染为真实拼图块：左凹右凸，开场卡仅凸、收尾卡仅凹**
- 卡牌 90 张 = **行为卡 70（五系）+ 修饰卡 20（语气 12 + 企划 8）**；节目槽初始 2 上限 5~6；**修饰槽 Lv3/8**；卡面双标识（系别图标 + 双端槽色）；信息分层
- **演出预算**：每场独立满额（改名自"精力"），上限 = 主播等级基准（Lv1=10…Lv10=20），压力 ≥80 → 预算 -3；energyCost 管"能不能用"、stressCost 管"敢不敢用"
- **素材 tag 系统**：materialRequire（无=不可用）/ materialBoost（有=×1.3）；剧本编排只显示兼容卡；素材与卡牌共用同一 tag 闭包
- **技能树 5×5**：每级系数 +15%（基准），Lv2/3/4/5 具名里程碑，Lv3 = "改规则"钩子
- **90 张卡分布表与 9 个 Build 原型入档**；语气卡门槛按功能挂技能（演/谈/歌），企划卡挂杂项力
- 卡牌字段 = 代码侧（axes/mood/energyCost/materialRequire/Boost/combo）+ prompt（plain string 片段，prompt 工程未设计）
- 素材"有含量"（depth/progress/freshness），连续型 + 消耗型；素材与卡牌共享公共内容协议和 tag 闭包，但保持独立类型/库存/UI；素材自带四轴修正
- 直播预结算架构（开播掷骰，LLM 纯演绎）；跳过永远安全；四轴结算管线
- 粉丝构成五类互斥向量 + 反哺公式
- **UI**：开播向导三步（素材与形象→剧本编排→确认开播）；三属性在 OS 托盘不在直播软件；**不评头论足原则**（无匹配警告/建议）；沿用上次配置快捷开播
- **角色定稿**：阮云柚 / 陆鸢鸢 / 鹿铃 / 睡不醒的河马 / 苏禾；命名规则三条
