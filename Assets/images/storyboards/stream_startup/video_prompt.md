# 直播开机动画视频生成 Prompt

使用提供的四张 `2×2` 分镜板作为连续参考，分镜板顺序为 01 → 02 → 03 → 04；每张内部按左上 → 右上 → 左下 → 右下播放。

生成一段 18.5 秒、16:9、24fps 的二维视觉小说风格动画。人物身份、脸型、短紫发、金色眼睛、身材比例和黑色猫耳连帽日常服严格遵循参考图。线条清晰，使用明亮平涂和少量赛璐璐阴影。房间、桌面、显示器、环形灯、麦克风与摄像头的位置在所有镜头中保持连续。

整体是一段快节奏的开机蒙太奇。镜头短促、干净，主要使用硬切；每个镜头只表现一个明确动作。

时间线：

- 0.0–0.7 秒：桌下微距，手指拨动插排开关。
- 0.7–1.4 秒：主机低角度特写，按下电源键。
- 1.4–2.1 秒：机箱风扇开始旋转，指示灯亮起。
- 2.1–3.4 秒：背面过肩镜头，黑色显示器亮起柔和的启动光。
- 3.4–4.2 秒：手指旋转环形灯旋钮，灯光点亮。
- 4.2–5.4 秒：俯拍，女主拉近椅子并坐入直播位置。
- 5.4–6.5 秒：侧面特写，麦克风悬臂被顺畅拉近。
- 6.5–7.6 秒：显示器侧面机位，轻微调整追踪摄像头角度。
- 7.6–8.4 秒：俯拍键盘，完成一次快捷操作。
- 8.4–9.3 秒：过肩镜头，只有无文字面板和状态形状的直播界面依次就绪。
- 9.3–10.3 秒：侧面近景，手指轻敲一次麦克风。
- 10.3–11.4 秒：音量条随敲击快速跳动，屏幕边缘映出她的金色眼睛。
- 11.4–12.8 秒：背后中景，她用双手把猫耳兜帽放到颈后，短发自然落下。
- 12.8–13.9 秒：侧面近景，她看着屏幕边缘的倒影，轻轻整理刘海。
- 13.9–15.1 秒：摄像头正面视角，她闭眼吸气，肩膀放松，然后坐直。
- 15.1–17.2 秒：同一正面视角，她睁开眼睛，从私下的疲惫神情自然切换成温和、熟练但不夸张的营业笑容，手落到鼠标上并点击开播。
- 17.2–18.5 秒：环形灯形成明亮圆形构图，白光迅速充满画面，作为切入现有 3D VTuber 直播画面的匹配转场。视频停在白光满屏，不生成新的 VTuber 外观。

动作节奏由设备声音推动：插排开关、主机按键、风扇启动、灯光旋钮、椅轮、悬臂移动、键盘、麦克风轻敲和鼠标点击形成连续节拍。最后一个节拍后短暂停顿，让她的笑容停留约半秒，再进入白光转场。全片无对白。

服装连续性：小圆形骷髅饰件始终固定在猫耳兜帽布料上。兜帽戴起时它位于兜帽上；兜帽放下后它随兜帽留在颈后。它不会移动到头发、刘海或脸侧。青色与粉色耳朵、抽绳和袖带的位置与颜色始终一致。

画面稳定性：人物五官、发型、服装结构、房间布局和设备造型跨镜头一致。人物动作自然克制，物体只在被操作时移动。保持二维视觉小说画法和清晰平涂质感。
