# 场景剧本大纲：图书馆邂逅

## 场景基本信息
- **场景ID**: scene_10_library_encounter
- **场景标题**: 图书馆的午后
- **背景**: 学校图书馆（安静、阳光透过窗户洒在书架上）
- **时间**: 放学后的下午
- **氛围**: 宁静、略带紧张（初次单独相遇）
- **BGM**: 轻柔的钢琴曲，略带温馨感

## 出场角色
- **主角**（玩家角色）：同班同学，对Alice有好感但未表白
- **Alice**：正在图书馆看书，意外遇到主角

## 场景开场
**背景**：图书馆内景，阳光透过窗户洒在书架上，营造出宁静的氛围。

**[旁白]** 放学后的图书馆格外安静，只有翻书页的沙沙声和窗外偶尔传来的鸟鸣。你本想借几本参考书，却在文学区的角落看到了一个熟悉的身影。

> 显示角色: Alice（靠窗位置），表情: 专注看书

**[Alice]** （低头看书，轻声自语）"这句话写得真美呢……"

**[旁白]** 她似乎完全沉浸在书的世界里，阳光洒在她浅棕色的短发上，让发梢染上了一层金色。

## 核心对话（选项前）

**[主角内心]** （看到Alice独自在图书馆看书）
- 选项A：主动上前打招呼
- 选项B：默默离开，不打扰她

## 选项A：主动搭话

### 分支A1：自然打招呼
**[主角]** "Alice同学？真巧，你也在这里看书啊。"

**[Alice]** （惊讶地抬头，书差点掉下来）"诶？！是、是你啊……那个……好巧呢。"
> 切换表情: Alice → 惊讶（脸微红）

**[主角]** "在看什么书呢？"

**[Alice]** （稍微镇定下来，展示书封面）"是、是一本诗集呢。作者的文字很温柔……"
> 切换表情: Alice → 微笑（略带害羞）

**[主角]** "我可以坐这里吗？"

**[Alice]** （点头，声音更小了）"嗯……请坐。"
> 内心独白: 啊，心跳得好快……为什么他会在这里？

### 后续发展A1-1：深入交谈
**[主角]** "你也喜欢诗歌吗？"

**[Alice]** "是的呢……总觉得诗歌能表达出平时说不出口的心情。"
> 切换表情: Alice → 认真

**[主角]** "我偶尔也读一些，但不太懂……"

**[Alice]** （眼睛亮起来）"那个……如果你有兴趣的话，我可以推荐几本入门诗集呢。"
> 内心独白: 诶？我居然主动说了这种话……

**结果**：好感度+5，解锁"诗歌话题"后续对话

### 后续发展A1-2：尴尬冷场
**[主角]** "呃……今天天气不错。"

**[Alice]** "是、是啊……阳光很温暖呢。"
> 切换表情: Alice → 尴尬（视线飘忽）

**[旁白]** 对话陷入了尴尬的沉默，两人都不知道该说什么。

**[Alice]** （小声）"那个……我差不多该回去了……"
> 切换表情: Alice → 抱歉

**结果**：好感度不变，Alice提前离开

## 选项B：默默看书

### 分支B1：选择旁边的座位
**[主角内心]** 还是不要打扰她比较好……但可以坐在附近。

**[旁白]** 你选择了Alice旁边的桌子坐下，开始翻阅自己的书。偶尔能听到她翻书页的声音和轻轻的叹息。

**[Alice]** （轻声自语）"啊……这里写得真好。"
> 切换表情: Alice → 感动（眼眶微湿）

**[主角内心]** （偷看Alice）她看书的样子好认真……要不要说点什么？

### 分支B1-1：最终开口
**[主角]** （犹豫后）"那个……你好像很喜欢这本书？"

**[Alice]** （吓了一跳）"诶？！你、你什么时候……"
> 切换表情: Alice → 惊慌（书掉在地上）

**[主角]** "抱歉，吓到你了。我刚刚坐在那边……"

**[Alice]** （捡起书，脸更红了）"没、没关系呢……是我太专注了。"
> 内心独白: 他一直在旁边吗？！好丢脸……

**结果**：好感度+3，Alice对主角的印象是"细心但有点吓人"

### 分支B1-2：始终沉默
**[旁白]** 你始终没有开口，只是偶尔抬头看看Alice。她似乎完全没有注意到你的存在。

**[Alice]** （合上书，看了看时间）"啊，已经这个时间了……"
> 切换表情: Alice → 遗憾

**[旁白]** Alice轻轻叹了口气，把书放回书架，离开了图书馆。

**[主角内心]** 还是没能说上话啊……

**结果**：好感度+1，解锁"观察者"成就

## 分支剧情走向总结

### 选项A（主动搭话）路线：
1. **成功路线**：自然交谈 → 发现共同兴趣（诗歌） → 好感度大幅提升 → 约定下次一起讨论诗歌
2. **普通路线**：尴尬对话 → 短暂交流后结束 → 好感度小幅提升 → Alice对主角有印象但不算深刻
3. **失败路线**：说错话 → Alice感到困扰 → 提前离开 → 好感度下降

### 选项B（默默看书）路线：
1. **观察者路线**：默默观察 → 最终开口 → 意外但真诚的交流 → 建立"细心"的印象
2. **守护者路线**：始终不打扰 → Alice离开后才发现主角 → 后续在其他场景有"似曾相识"的对话
3. **错过路线**：完全无交流 → 只是图书馆的陌生人 → 需要其他场景重新建立联系

## 关键对话设计要点

### Alice的对话特点：
1. **语气词**：大量使用"呢"、"啊啦"、"诶～"
2. **犹豫感**：对话开头常有"那个……"
3. **内心独白**：展现表面温柔与内心紧张的反差
4. **成长暗示**：在放松时会主动表达自己的兴趣

### 主角对话设计：
1. **选项A**：主动但不过分热情，给Alice留出回应空间
2. **选项B**：体贴但可能错过机会，需要后续弥补
